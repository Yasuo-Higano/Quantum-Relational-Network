# 1. 最初に行うべきこと：Yukawa 論文の即時訂正

これは次期候補の一つではなく、**v34.1 の必須作業**です。

FollowUp は、整数反対称行列 (F) について

[
\operatorname{Pf}(F)=3,\qquad F^{\mathsf T}F=3I
]

を同時に満たす厳密反例を構成しています。したがって二つの skew singular value はともに (\sqrt3) であり、

> 「Pfaffian が素数 3 だから二つの磁気固有面は不均等になり、一方が平坦化する」

という裸の推論は偽です。FollowUp はこれを `YUK-005` の反例として明示しています。 ([GitHub][2])

現在の `geometric-yukawa-full.md` は Abstract で「index 3, being prime, forces one magnetic eigenplane to flatten」と書き、そこから generation pairing の一般的既約性を結論しています。`QRN-YUK-015` と `QRN-META-013` にも同じ推論が入っています。これは limitation の追記だけでは直りません。主張そのものを分解する必要があります。 ([GitHub][3])

推奨する処理は次です。

### `QRN-YUK-015` を二つに分割する

**QRN-YUK-015A：有限走査結果**

* 登録された (N)、磁束行列、Wilson 配置、縮退判定規則の範囲内では、厳密三重縮退を保った候補が浅い階層しか作らなかった。
* C4 の有限模型結果として保持する。
* 「探索した admissible family の範囲内」という限定を claim 本文に入れる。

**QRN-YUK-015B：素数 Pfaffian による一般 no-go**

* `status: refuted_as_stated`
* FollowUp の整数反例を最小証人として登録する。
* Universal claim としては撤回する。

Abstract の結論は、少なくとも次まで弱めるべきです。

> Within the explicitly scanned finite-lattice family, all exactly threefold-degenerate tilted four-torus candidates were too shallow. Primality of the Pfaffian alone does not imply unequal magnetic skew scales; a general exclusion of unpaired index-three constructions remains open pending explicit lattice-arithmetic and metric-compatibility conditions.

また `QRN-META-013` の「位置・向き・傾きの全代替が素数 3 の構造論で落ちた」も撤回または有限走査限定に変更します。

重要なのは、**FollowUp が organizationally external でないことと、反例の有効性は別問題**だということです。普遍命題は一つの正しい厳密証人で反証されます。独立性は証人を信用する強さに影響しますが、主リポジトリ側で整数演算によって再検算すれば数学的決着です。

さらに、この反例が示す一般的教訓は重要です。

> **Pfaffian は整数交代形式の代数的・位相的情報であり、skew singular value は選択された計量に依存する幾何学的情報である。前者から後者を導くには、別途 metric/lattice compatibility bridge が必要である。**

これは QRN 全体で繰り返し警戒すべき「位相不変量から計量的異方性への無証明な昇格」です。

# 4. v34.3：第四の no-go と観測証明書

## 第四の no-go：有限データ昇格不能定理

登録された観測モデルのパラメータを (\theta)、有限データの分布を (P_\theta)、exact な v33 裁定を (q(\theta)) とします。

異なる裁定を必要とする二つの interface (\theta_0,\theta_1) が有限データ上で近い分布を持つなら、強制回答器の誤りには

[
\inf_\delta
\frac{
P_{\theta_0}[\delta\neq q(\theta_0)]
+
P_{\theta_1}[\delta\neq q(\theta_1)]
}{2}
\ge
\frac{1-\operatorname{TV}(P_{\theta_0},P_{\theta_1})}{2}
]

という下限があります。

観測契約が不完全で (P_{\theta_0}=P_{\theta_1}) なら、強制回答の平均誤り下限は (1/2) です。つまり、

> rank、cross-talk、glue、(J) の境界付近で有限データから常に正しい強制回答を返すことは不可能であり、abstention か追加実験が必要である。

これを有限標本・有限結果空間版で Lean 証明し、一般版を論文で証明するのがよいでしょう。

## 正側：Robust Promotion Theorem

データ (D) から、真の interface を確率 (1-\alpha) 以上で含む**同時信頼集合**

[
C_\alpha(D)\subseteq\Theta
]

を構成します。点推定を exact reader に渡すのではなく、集合全体を渡します。

[
Q_\alpha(D)={q(\theta):\theta\in C_\alpha(D)}.
]

裁定は次のようにします。

* (Q_\alpha(D)) が単一の admissible orbit
  → `RobustExact`
* 複数だが既知の同値関係内
  → `EquivalenceClassOnly`
* answerable / non-answerable または閾値の両側を含む
  → `Straddled`
* 必要な観測 channel が欠ける
  → `InsufficientObservation`
* 登録 noise model が棄却される
  → `OutOfDomain`

誤った昇格が起きるなら真の (\theta) が (C_\alpha(D)) の外にあるため、

[
P_\theta(\text{wrong promotion})\le \alpha
]

が得られます。

ただしこれは無条件の誤昇格確率です。conditional selective risk については

[
P(\text{wrong}\mid\text{answer})
\le
\frac{\alpha}{P(\text{answer})}
]

なので、coverage だけから selective risk (\le\alpha) と言ってはいけません。answer rate の下限か、回答条件付きの保証が別途必要です。

## 新しい禁止変換

第三十四期では少なくとも次を追加します。

```text
22. PointEstimate              ↛ AccessibilityCertificate
23. MarginalIntervals          ↛ JointConfidenceRegion
24. GoodnessOfFit              ↛ NoiseModelValidity
25. CalibrationAt(t₀)          ↛ ValidAt(t₁)
26. MeanCrosstalk              ↛ UniformCrosstalkBound
27. LocalChartCoverage         ↛ GlobalGlueCoverage
28. ZeroHoldoutErrors          ↛ ZeroPopulationRisk
29. ModelConditionalCertificate ↛ ModelFreeCertificate
```

特に 23 は重要です。複数の 95% marginal interval の直積は 95% joint region ではありません。GST の統計議論でも、各パラメータの (\alpha) interval を積にすると joint coverage は概ね (\alpha^k) になり、真の joint region には別の補正が必要だと明示されています。 ([ar5iv][6])

また、state・measurement・gate を別々に「既較正」と仮定するより、GST のように準備・測定・操作を相互に整合する一つの対象として推定し、gauge orbit 上で信頼集合を扱うのが第三十三期のテーゼにも合います。 ([ar5iv][6])

有限測定からの点推定には、それだけでは operational significance がなく、誤差領域が必要だというのが量子 tomography の基本的な統計構造です。 ([arXiv][7])

# 6. HOLD-10 は「30セル満票」だけでは不十分

HOLD-9 の 9 answerable cell と FollowUp の 77 `Answer` は、いずれも観測された誤りは 0 でした。 ([GitHub][1])

しかし、仮に回答セルを i.i.d. Bernoulli 試行と解釈しても、誤り 0 件に対する片側 95% 上限は、

* 0 / 9：28.3%
* 0 / 77：3.82%

です。

つまり `selective risk = 0` は **有限 holdout 上の観測誤りが 0** という意味であり、母集団リスク 0 の証明ではありません。母集団誤り率の片側 95% 上限を 1% 未満にするには、誤り 0 の answer cell が少なくとも 299 件必要です。しかも現在のセルは異質な adversarial archetype なので、単純な i.i.d. 解釈自体が追加仮定です。

したがって HOLD-10 は二層にします。

## HOLD-10S：意味論 adversarial holdout

30 セル、5 群 × 6 セル。

| 群                          | 代表セル                                                                                                                           |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| noise / provenance         | independent shot、相関した ± run、drift、missing channel、model mismatch、target hash mismatch                                          |

| structured / resource      | dense=Pauli、quadratic Majorana、interval cost、profile morphism、ScopeExceeded、general-GKLS OOD                                   |

## HOLD-10C：coverage campaign

凍結した生成分布から少なくとも 600 セルを生成し、300 以上の回答セルを確保します。

主要指標は、


さらに drift・memory・correlated noise を扱う lane を一つ必須にします。現実の装置では i.i.d. 仮定違反が不確実性を過小評価しうるため、少なくとも bounded martingale または time-averaged certificate を実装すべきです。 ([arXiv][8])

# 7. 実測 lane を完成条件に入れる

synthetic shot noise を「実測ノイズ」と呼んではいけません。次の二 lane を分けます。

### Synthetic coverage lane

* 真の interface が既知
* confidence set の coverage を直接採点
* adversarial boundary と model misspecification を生成可能

### Recorded experimental lane

* 実際に物理装置から得た repeated finite-shot record
* 真の latent interface は未知
* model fit、drift、予測 calibration、unused-channel prediction を採点
* vendor topology や hidden permutation は freeze 後に開示
