# 2. 第三十一期を束ねる第一の定理：熱的 Gaussian の静的逆問題

現在の熱的 Gaussian 生成器は

[
C=(I+e^{\beta(h-\mu I)})^{-1}
]

なので、(0\prec C\prec I) なら

[
K(C)
=\log!\left[(I-C)C^{-1}\right]
=\beta(h-\mu I).
]

リポジトリの v29.6 も、実際に (C=(I+e^{\beta h})^{-1}), (h=-A) を生成に使っています。

したがって、

* (\beta) 既知なら (h-\mu I) を完全復元できる。
* (\beta) 未知でも、非対角結合の支持、相対強度、位相は正の全体スケールを除き復元できる。
* (\mu) の不定性は一様な対角シフトだけなので、空間隣接には影響しない。
* ノード内基底変換 (U=\bigoplus_i U_i) に対して
  (K_{ij}\mapsto U_iK_{ij}U_j^\dagger)。
* よって (K_{ij}) の特異値や Schatten ノルムはノード内基底不変である。

ただし、ここには三つの重要な制限があります。

### 2.1 これは新しい QRN 法則そのものではない

自由フェルミオン状態と相関行列から quadratic parent を得る関係は標準的です。Gaussian 状態の reduced density matrix が自由粒子 Hamiltonian を持つ熱的形式になることは既知であり、近年は Gibbs 状態からの Hamiltonian learning や局所 inversion も独立した研究分野になっています。([arXiv][4])

したがって、この逆変換は次のように扱うべきです。

* 名称：`GaussianGibbsInverseOracle`
* 種別：oracle ceiling / identifiability upper bound
* QRN 固有予言：不可
* PRED-019：登録不可
* BridgeLawCertificate：この式だけでは登録不可

新規性が生じるのは、**静的・動的・局所・大域・純粋・熱的・Gaussian・非Gaussianを横断した識別可能性相図、厳密な no-go 証明書、観測資源別の読み出し限界**です。

### 2.2 logit が返すのはまず「親 modular 生成子」である

完全な (C) からは、それと整合する Gaussian parent (K(C)) を構成できます。しかし、実際の物理的時間発展生成子がそれであるためには、

* 状態が Gaussian であること
* その物理的生成子に対する Gibbs 状態であること
* (\beta,\mu) の意味が物理的に与えられていること

が必要です。

静的 (C) だけから、`ParentModularGenerator` を `PhysicalGenerator` に変換してはいけません。型で分離すべきです。

### 2.3 現行 B2 とは別物である

現行 B2 は、各二ノード部分行列 (C_{{i,j}}) を先に切り出し、その後に logit を適用しています。また固有値を clamp しています。([GitHub][5])

一般には

[
f(P_CP)\neq P f(C)P
]

なので、

* `GlobalPhysicalParentBlock`: 全系 (C) に logit をかけてから block 抽出
* `ReducedModularBlock`: 二ノード RDM に logit をかける現行 B2

は異なります。後者は環境によって renormalize された reduced modular coupling です。

この差を曖昧にせず、観測予算の両端として比較するべきです。

# 3. 第三十一期の主役にすべき新しい応答法則

不変ノルム核と臨界頑健核を同時に解く最も有望な方法は、**局所バイアス応答の短時間曲率**です。

既知のノード因子分解を

[
\mathcal H_1=\bigoplus_i\mathcal H_i
]

とし、(P_i) をノード (i) への射影とします。次の二つの Gaussian probe 状態を考えます。

[
C_i^\pm(0)=\frac12 I\pm\epsilon P_i,
\qquad 0<\epsilon<\frac12.
]

一体生成子 (h) の下では

[
C(t)=e^{-iht}C(0)e^{iht},
\qquad
\dot C(0)=-i[h,C(0)].
]

したがって (j\neq i) に対して

[
P_j\bigl(\dot C_i^+(0)-\dot C_i^-(0)\bigr)P_i
=-2i\epsilon P_jhP_i.
]

つまり、full coherence response が測定できれば、ノード間生成子 block を局所基底共変な形で直接復元できます。

さらに、ノード (j) の総密度

[
n_j(t)=\operatorname{Tr}(P_jC(t))
]

しか測れなくても、

[
\frac{
\ddot n_{j,+}(0)-\ddot n_{j,-}(0)
}{4\epsilon}
============

\left|P_jhP_i\right|_F^2.
]

これは第三十一期の中心定理候補です。

## この法則の利点

1. **ノード内基底不変**
   (h_{ji}\mapsto U_jh_{ji}U_i^\dagger) なので Frobenius ノルムは不変です。

2. **密度だけで読める**
   full (C(t)) tomography が不要で、短時間密度曲率だけで結合強度が得られます。

3. **純粋状態の rank 欠損に依存しない**
   equilibrium ground state の logit を使わないため、P6/693 の `sign(A)` no-go と衝突しません。

4. **臨界境界増強を回避できる**
   長距離の equilibrium correlation を近傍判定に使わず、生成子の短時間局所応答を直接読むためです。

5. **B3 と B4 を本当に統一できる**
   B3 は (|C_{ij}|*F^2)、局所バイアス曲率は (|h*{ij}|_F^2)。両者を「operator block の不変ノルム」として一つの atlas に置けます。現行 B4 も局所注入後の密度前線を観測する設計ですが、到着時刻に圧縮する前の短時間微分を新しい基礎量にできます。([GitHub][6])

これは「静的単独不可・局所操作併用可」を、到着時刻の経験則ではなく有限行列の恒等式にできます。

ただし、これは **状態だけからの読み出しではなく、局所 probe preparation が許された能力**です。証明書名は例えば

```rust
SpatialMetricGivenFactorizationAndLocalBiasAccess
```

のように、観測資源まで型に含めるべきです。

## v31.1：条件数まで定理にする

[
f(x)=\log\frac{1-x}{x},
\qquad
f'(x)=-\frac{1}{x(1-x)}.
]

[
\delta(C)=\min{\lambda_{\min}(C),,1-\lambda_{\max}(C)}
]

を spectral margin とし、少なくとも局所的には

[
|\Delta K|
\lesssim
\frac{|\Delta C|}{\delta(1-\delta)}
]

という形の安定性証明書を作ります。

これにより、

* full-rank かつ良条件：exact/stable
* full-rank だが低温で ill-conditioned：regularized estimate
* projector：equivalence class only
* domain 不明：abstain

を機械的に分けられます。

正温度の局所 Hamiltonian に対する density matrix の空間減衰には既存の理論的背景があるため、patchwise inversion の収束は有望な研究仮説です。ただし、真の幾何半径を使って patch を選ぶと循環するので、開発用 `OraclePatch` と観測から構築する `OperationalPatch` は別型にしてください。([arXiv][7])

## v31.4：factorization no-go

少なくとも number-conserving Gaussian mode factorization の範囲では、(C) の固有モード基底を取れば (C) は対角化され、モード間静的相関は消えます。

したがって、任意の mode basis が許されるなら、静的状態だけから元の空間的 factorization を一意選択できません。

FactorizationBridge の入力は、状態だけではなく、例えば次のような operational structure である必要があります。

[
{\text{preparations},\text{local interventions},
\text{measurements},\text{compatibility/commutation}}.
]

現在の schema は `RelationalDecomposition` を `defined` かつ「入力でなく読み出し」と書く一方、仕様本文では設計目標であり現行 bridge は因子分解を入力にすると明記しています。この意味論差は v31.0 で修正した方がよいです。([GitHub][8])

## v31.4：operator atlas

局所演算子基底 (O_i^a) に対して、

[
X_{ij}^{ab}
=\langle O_i^a O_j^b\rangle_c,
\qquad
R_{ij}^{ab}(t)
=i\theta(t)\langle[O_i^a(t),O_j^b]\rangle
]

を作り、局所 Gram 行列 (G_i) で

[
\widehat X_{ij}
=G_i^{-1/2}X_{ij}G_j^{-1/2}
]

と whiten します。

この特異値、operator norm、Frobenius norm を不変量にします。最大相関を covariance matrix から構成する考え方には既存の Gaussian maximal correlation が参考になります。([arXiv][9])

Gram 行列が rank-deficient の場合は、無条件の擬似逆行列ではなく、

```rust
ObservableSupportCertificate { rank, threshold, nullspace }
```

を返し、必要なら abstain させます。

## v31.5：非Gaussianは必須

Gaussian (C) の logit は、非Gaussian状態では物理 Hamiltonian を返しません。また、同じ one-body (C) を持つ非Gaussian状態は多数存在するため、(C) だけから Gaussian 性を証明することもできません。

したがって、

```rust
GaussianityEvidence::ByConstruction
GaussianityEvidence::WickResidualBound
GaussianityEvidence::Unknown
```

を導入するべきです。

非Gaussian test は、まず以下の二系列で十分です。

1. spinless (t)-(V) 系
   (V=0) から連続的に Gaussian 破れを追跡できる。

2. 既存の Z2 / ConstrainedToyCore 系
   one-body Gaussian 描像に還元できない対照。

ここで response atlas が失敗した場合、結果は削除せず、

> Gaussian Gibbs family に限定された readout

として確定します。非Gaussian transfer なしで一般的な GeometryBridge に昇格してはいけません。

## v31.6：3D はここで初めて行う

現在の homology engine は clique complex を 3-simplex まで列挙し、(\beta_0,\beta_1,\beta_2) を計算しています。([GitHub][10])

3D の (\beta_3) を正しく計算するには

[
H_3=\ker\partial_3/\operatorname{im}\partial_4
]

なので、**4-simplex まで列挙する必要があります**。

最初の engine anchor は次がよいです。

* (T^3:(1,3,3,1))
* (S^3:(1,0,0,1))
* 3-ball: ((1,0,0,0))

また3-manifold 判定では、vertex link が閉点で (S^2)、境界点で (D^2) になることを検査します。単に Betti 数が合うだけでは不十分です。

## v31.2 — LocalBiasCommutatorLaw

P_j (Cdot_i^plus - Cdot_i^minus) P_i
