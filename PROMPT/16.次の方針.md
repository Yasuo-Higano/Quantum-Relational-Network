## 結論

2026年8月4日時点で、次期の主題は **「外部化と観測商」** に固定すべきです。

v35 で閉じたのは、登録済み合成母集団に対する器械の安全性・再現性・有限データ意味論です。HOLD-10C の誤昇格上限 0.63% は強い結果ですが、これは凍結した合成生成分布上の上限であり、自然・実装置・外部実装へ転送できる上限ではありません。リポジトリ自身も instrumental closure と判定し、bridge law、PRED-019、自然観測、外部再現、実記録をゼロのまま残しています。FollowUp も有限次元の中核を Partially Replicated とした一方、同一 human operator であり組織的外部再現ではなく、自然界の予測・検証はないと明記しています。([GitHub][1])

# 1. 最初に v35.1 として直すべき仕様

## 1.1 RECORD の prose と schema が一致していない

`RECORDED_LANE.md` は「shot 配列または counts＋取得時刻」を許していますが、現行 JSON Schema は各 channel に `shots` を必須とし、counts を表現できません。また、取得時刻は device 全体に一つだけで、各チャネルの source、target、probe sign、ε、evolution time、batch、program hash などが型になっていません。([GitHub][2])

推奨する v2 は一つの可変 JSON ではなく、次の三段階です。

1. `preregistration-v2.json`

   * analysis commit
   * observation contract hash
   * calibration channel IDs
   * held-out channel IDs
   * prediction commitment
   * score rule
   * model-misspecification gates
   * topology/mapping commitment

2. `acquisition-v2.json`

   * immutable raw artifact hashes
   * `source_id`, `target_id`, `probe_sign`, `epsilon`, `evolution_time`
   * batch ごとの開始・終了時刻
   * ordered shots、または timestamped batch counts

   * acquisition randomization seed
   * `used_in_calibration` の必須 boolean

3. `disclosure-v2.json`

   * prediction plaintext
   * hidden topology・label mapping の plaintext
   * commitment 照合結果
   * score
   * failure を含む最終 verdict

各 object に `additionalProperties: false` を入れ、shots と counts は `oneOf` で区別すべきです。

## 1.2 counts-only では v35 の相関検査ができない

現行 recorded lane の drift 検査は split-half ですが、HOLD-10 は同じ周辺分布を持つ持続的 Markov 鎖が split-half を通過し得るため、遷移数ゲートを追加しました。したがって、順序を失った aggregate counts だけでは、v35 が要求する serial-correlation 検査ができません。([GitHub][1])

型を少なくとも次の三つに分けるべきです。

* `OrderedShots`: 遷移数ゲートまで実行可能
* `TimestampedBatches`: batch 間 drift・overdispersion のみ検査可能
* `AggregateCounts`: iid certificate を発行禁止。`CorrelationUnassessed` を返す

最初の counted run は `OrderedShots` または十分細かい `TimestampedBatches` に限定するのが安全です。

# 2. 主理論課題：開放系の signed response が何を識別するか

## 2.1 まず一般 GKLS ではなく quasi-free lane を閉じる

最近の研究では、既知の Pauli-GKSL 辞書に対する短時間応答の線形反転だけでなく、積状態準備・短時間発展・単一 qubit Pauli 測定から未知の局所 Lindbladian 構造を学習する方向まで進んでいます。したがって、QRN が単に「一般 GKLS 係数推定器」を作っても差別化は弱いです。([arXiv][4])

QRN の固有の課題は、

* density-only signed probes
* given factorization
* block-unitary gauge
* fail-closed verdict
* finite-data simultaneous confidence set

という弱い観測契約の下で、**識別できる最大商を正確に記述すること**です。

## 2.2 次に証明すべき基本定理

有限モード、number-conserving、quasi-free、Markovian な開放系で、normal covariance が

[
\dot C(t)=X C(t)+C(t)X^\dagger+Y
]

に従うとします。(X) は coherent と dissipative の双方を含む有効 drift、(Y) は affine な注入・noise 項です。quasi-free Lindblad 系で covariance が閉じること、および open quadratic system が非エルミート single-particle matrix で記述されること自体は既知です。([arXiv][5])

同一の (X,Y) に対して、

[
C^\pm(0)=C_0\pm\epsilon P_i,\qquad P_iP_j=0
]

を用いると、差分 (D=C^+-C^-) は

[
\dot D=XD+DX^\dagger,\qquad
D(t)=2\epsilon e^{Xt}P_i e^{X^\dagger t}
]

となり、affine 項 (Y) は厳密に消えます。したがって

[
n_j^\pm(t)=\operatorname{Tr}(P_j C^\pm(t))
]

について、

[
\boxed{
\frac{\ddot n_j^+(0)-\ddot n_j^-(0)}{4\epsilon}
===============================================

\left|P_j X P_i\right|_F^2
}
]

が得られます。1次元 node なら右辺は (|X_{ji}|^2) です。

これは matrix exponential の解析を使わず、ODE を二回微分して trace の巡回性から Lean 化できます。実際、

[
D''(0)
======

2\epsilon\left(X^2P_i+2XP_iX^\dagger+P_i(X^\dagger)^2\right)
]

であり、(P_iP_j=0) により両端項の trace が消え、中項だけが Frobenius norm を与えます。

### 重要な解釈

閉鎖系なら (X=-ih) なので既存の

[
|P_jhP_i|_F^2
]

に戻ります。しかし開放系では、一般に曲率が読むのは **Hamiltonian topology ではなく effective-drift topology** です。

したがって新しい型は、

```text
OpenSignedCovarianceProbe
  -> EffectiveDriftTopology
```

であるべきです。

次の昇格は証明書なしでは禁止します。

```text
EffectiveDriftTopology
  ↛ HamiltonianTopology
```

許されるのは例えば、

```text
EffectiveDriftTopology
+ OffDiagonalDissipatorZero
  -> HamiltonianTopology
```

または、より一般的な `DissipatorLocalityCertificate` がある場合だけです。

## 2.3 明示的な反例候補

標準的な loss-only covariance 規約

[
X=-ih-\frac12\ell\ell^\dagger
]

で、次の二つを比較できます。

### coherent model

[
h=
\begin{pmatrix}
0&1\
1&0
\end{pmatrix},
\qquad \ell=0
]

なので (|X_{21}|^2=1)。

### dissipative model

[
h=0,\qquad
L=\sqrt2(c_1-c_2)
]

なら

[
X=
--

\begin{pmatrix}
1&-1\
-1&1
\end{pmatrix}
]

となり、やはり (|X_{21}|^2=1)。

従って両者は登録された off-diagonal 曲率統計では同じ重みを返しますが、一方は Hamiltonian edge、他方は純粋な collective loss です。

この反例が証明するのは **曲率統計から Hamiltonian support へ昇格できないこと**です。全時刻の時系列まで同一とは限らないので、no-go の observation contract を `CurvatureOnlyOpenResponse` と明示する必要があります。この scope discipline を FollowUp に最初に攻撃させるべきです。

## 2.4 全時刻応答の観測商

一般には、観測契約

[
\mathcal C=({\Xi_i},{O_j},T)
]

に対して、

[
\Phi_{\mathcal C}(\mathcal L)_{ji}(t)
=====================================

\operatorname{Tr}!\left(
O_j e^{t\mathcal L}(\Xi_i)
\right)
]

を定義し、

[
\mathcal L\sim_{\mathcal C}\mathcal L'
\iff
\Phi_{\mathcal C}(\mathcal L)
=============================

\Phi_{\mathcal C}(\mathcal L')
]

とします。科学的出力は (\mathcal L) ではなく

[
[\mathcal L]_{\mathcal C}
]

です。

quasi-free density response では、少なくとも

[
X\mapsto DXD^\dagger+i\omega I
]

という local phase/global frequency gauge が全時刻応答を保存します。実 projector を用いる場合には complex conjugation (X\mapsto X^*) も同じ modulus response を与えます。これらが generic case で観測同値の全てか、さらに大きな同値類が存在するかを分類することが、次の本格的な数学問題です。

## 2.5 GKLS と BCS witness の正しい境界

開放系では Hamiltonian 部と dissipative 部の分離自体が非一意であり、canonical traceless-jump gauge などを指定して初めて Hamiltonian の意味が固定されます。従って individual jump operators を直接出力するのではなく、superoperator、固定 basis 上の Kossakowski class、または canonical orbit を出力すべきです。([arXiv][6])

また、closed-system の

[
[H,Q]=0
]

は、open-system では gauge-invariant な

[
\boxed{\mathcal L^\dagger(Q)=0}
]

へ置き換える必要があります。

(\mathcal L^\dagger(Q)\neq0) だけでは BCS pairing を意味しません。particle gain/loss や charge-breaking jump でも同じ非保存が起こるからです。したがって、

```text
ChargeNonconservingResponse
  ↛ HamiltonianPairing
```

を新しい no-go とし、

```text
ChargeNonconservingResponse
+ DissipativeChargeConservationCertificate
  -> HamiltonianPairingWitness
```

のみを許すべきです。

### 推奨 theorem package

* **GQF-1 Affine Cancellation**
  signed probe 差分から (Y) が厳密に消える。

* **GQF-2 Effective-Drift Curvature**
  曲率が (|P_jXP_i|_F^2) を返す。

* **GQF-3 Hamiltonian-Promotion No-Go**
  dissipator certificate なしでは (|P_jhP_i|_F^2) に昇格不能。

* **GQF-4 Local-Dissipator Positive Reduction**
  off-diagonal dissipative drift がゼロなら閉鎖系式へ還元。

* **GQF-5 Charge Attribution No-Go**
  charge violation だけから pairing Hamiltonian を選べない。

* **GQF-6 Robust Open Promotion**
  有限 shot の同時信頼集合全体で effective-drift support が一定のときだけ回答。

この一群は、v34.6 の完成条件にある「広い観測契約族を排除する新しい厳密 no-go」の有力候補です。ただし、正式に数えるには observation contract を固定し、FollowUp の反例探索と Lean 証明を通す必要があります。

# 3. set-valued profile は「通常の関手」とは限らない

v34.5 は set-valued profile の単調性を器械化しましたが、関手性は成立するまで語彙を凍結しています。これは正しい判断です。([GitHub][7])

問題は二つあります。

第一に、資源を増やすと識別対象の同値関係自体が変わります。(b\preceq b') でより多くの資源を持つとき、

[
\sim_{b'}\subseteq\sim_b
]

となるなら、fine quotient から coarse quotient への写像

[
r_{b'b}:\Theta/{\sim_{b'}}
\longrightarrow
\Theta/{\sim_b}
]

が必要です。従って自然な構造は単純な covariant functor ではなく、quotient map を伴う contravariant または lax refinement です。

第二に、各予算で独立に作った (1-\alpha) confidence set は、標本ごとには自動的に nested になりません。coverage を持つことと、

[
C_{b'}(D)\subseteq C_b(D)
]

は別問題です。関手性を得るには、

* 共通 master data の restriction
* cumulative intersection
* anytime-valid confidence sequence
* 全 budget に対する同時誤差配分

のいずれかで samplewise nesting を構成する必要があります。

その条件下で初めて、

[
r_{b'b}!\left(Q_{b'}(D)\right)
\subseteq
Q_b(D)
]

を証明できます。

### 推奨定理

* **RPF-1 Non-Functoriality No-Go**
  arbitrary budget-wise confidence sets には自然な関手性はない。

* **RPF-2 Conditional Refinement Theorem**
  common latent space、nested confidence sets、compatible quotient maps があれば lax refinement が成立。

* **RPF-3 Margin Stability**
  confidence set の Hausdorff 摂動が decision boundary までの margin 未満なら verdict set は不変。

* **RPF-4 Global Discrete Instability**
  decision boundary を跨ぐため、離散 verdict への global Lipschitz stability は存在しない。

* **RPF-5 Persistence Corollary**
  現在の chain length ≥ 2 は、上の refinement object に対する離散 persistence criterion として導出する。

set-valued な時間依存 graph と interleaving stability には既存研究があるため、「set-valued stability」自体を新規性にしてはいけません。QRN の新規性は、観測商・gauge orbit・有限データ confidence set を同時に扱う点に置くべきです。([arXiv][8])

# 4. D2-R は研究ではなく、今や配布実験である

D2-R の funnel は全段階ゼロで、outreach ledger もゼロです。つまり現在の blocker は validator や定理ではなく、実際に第三者へ届けて参加者を得ることです。([GitHub][9])

D2R-v1 は変更してはいけません。有効報告一件で足りること、protocol・schema・判定規則を事後変更しないこと、成功しても解除されるのは `spatial_topology_given_factorization` の外部独立性だけであることが既に凍結されています。([GitHub][10])

推奨する固定 campaign は次です。

* 対象を3群に分け、各10件、合計30件の適格な直接 outreach を記録する。

  * Hamiltonian/Lindbladian learning
  * quantum network topology
  * TDA/reproducibility/formal methods

* 配布物は一枚の challenge summary、凍結 protocol、空の report template、schema validator、QUAL 用チェックリストに限定する。

* 数値 kernel、実装骨格、翻訳コードは渡さない。

* 質問は公開 ambiguity ledger に集約し、規範文の変更ではなく non-normative clarification として扱う。

* 30件終了時点で preregistration がゼロなら、物理や定理の失敗ではなく
  `protocol_externalizability: failed_at_current_burden`
  と記録する。

* その後にのみ D2R-v2 を設計する。v1 の条件は変更しない。

将来の v2 では「同じ AI か否か」だけで独立性を分類するのは粗すぎます。human/org、source access、shared code/kernel、shared prompt/workspace、model/revision、secret provenance を独立の軸として記録し、`external verification` と `source-blind clean-room` を分離すべきです。現行 v1 の判定を遡及変更してはいけません。

また、「局所測定から network topology を推論する」こと自体には既に先行研究があります。QRN の位置づけは、最初の topology inference ではなく、**signed curvature の厳密則、given-factorization scope、gauge-invariant block weight、no-go、fail-closed finite-data certificate** に置く必要があります。([arXiv][11])

# 5. 最初の実データ run

## 5.1 R0 と R1 を分ける

* **R0 protocol shakedown**
  schema、commit、raw-data ingestion、drift gate の検査。科学的完成条件には数えない。

* **R1 counted prediction**
  blind mapping、未使用チャネル、事前登録 score を持つ本走行。

R1 は 4–8 node 程度で十分ですが、少なくとも次を含めるべきです。

* hidden nonzero edge
* hidden zero edge
* calibration に使わない source–target pair
* calibration に使わない time point または batch
* 異なる二つの ε による signed-linearity check
* model-misspecification negative control

## 5.2 三者分離

1. **protocol custodian**
   analysis code、score、model gates を凍結。

2. **hardware operator**
   topology、physical-to-anonymous label mapping を知り、hash を commit。

3. **analyst**
   anonymous labels と calibration 部分だけを受け取り、held-out prediction を commit。

その後に operator が mapping と held-out record を開示します。

## 5.3 native と compiled を型で分ける

これは非常に重要です。

異なる evolution time ごとに別々にコンパイルされた digital circuit は、一般には一つの連続 semigroup (e^{t\mathcal L}) の標本ではありません。そのデータから hardware Hamiltonian topology を「発見した」と主張すると、compiler が埋め込んだ既知 topology を再読しているだけになる可能性があります。

したがって provenance を、

```text
NativeAnalogEvolution
CompiledDigitalChannelFamily
Emulator
```

に分けるべきです。

* `NativeAnalogEvolution`
  同じ pulse/evolution segment で duration だけを変えた場合。effective generator の主張候補。

* `CompiledDigitalChannelFamily`
  実データではあるが、主張可能なのは programmed channel response の calibration まで。

* `Emulator`
  synthetic lane。

少なくとも `evolution_family_id`、各 time point の program hash、± probe 間で evolution program が同一であることを記録してください。

## 5.4 claim scope

R1 が成功しても言えるのは、

> 登録した実装置・期間・観測契約において、signed response から得た effective-drift prediction が未使用チャネルの実測 confidence interval と整合した。

までです。

bridge law、PRED-019、emergent geometry、自然界一般へは昇格しません。現行完成条件も、実データ上の事前登録未使用チャネル予測の「的中」を要求しています。失敗した run は `recorded_runs` には数えますが、完成条件の hit には数えないのが整合的です。([GitHub][2])

# 6. FollowUp の使い方

FollowUp は外部再現としてではなく、**paper-closed theorem adversary** として使うべきです。shared human operator であることは final report 自身が明示しています。([GitHub][3])

論文更新は実装 commit ごとではなく、次の atomic packet 単位にします。

### Packet A — Open Response Conjecture Packet

* GQF-1 affine cancellation
* GQF-2 effective-drift curvature
* GQF-3 Hamiltonian-promotion counterexample
* GQF-4 local-dissipator reduction
* GQF-5 charge-attribution no-go
* full-time response gauge candidates

各 claim に必ず、

* status: theorem candidate / conjecture
* domain
* exact quantifiers
* input/output type
* gauge/equivalence
* falsifier
* forbidden interpretation

を付けます。期待数値出力は書きません。

### Packet B — Resource Profile Packet

* arbitrary confidence sets の非関手性反例
* nested confidence 条件下の refinement theorem
* margin stability
* boundary instability

### Packet C — OCS-2.0

A/B の反証と修正を受理した後にだけ有限データ spec を凍結します。OCS-1.0 が採用した「コードも記録済み出力値も不要な paper-closed specification」という規律は、そのまま維持すべきです。([GitHub][12])

## 5. v35.2 — Open signed-response quotient

有限モード number-conserving quasi-free GKLS lane を定義する。

dot(C) = X C + C X† + Y
C±(0) = C0 ± epsilon P_i
P_i P_j = 0
n_j = Tr(P_j C)

次を独立に導出し Lean で証明する。

GQF-2:
(ddot(n_j^+) - ddot(n_j^-)) / (4 epsilon)
  = || P_j X P_i ||_F^2

GQF-3:
上の応答は EffectiveDriftTopology を返す。

GQF-4:

||P_j X P_i||_F^2 = ||P_j h P_i||_F^2。

GQF-5:
L†(Q) != 0 だけから Hamiltonian pairing は識別できない。

GQF-6:
有限データ confidence set 全域で support verdict が一致するときだけ
RobustEffectiveDriftTopology を返す。

- affine gain/noise cancellation

- non-Markovian or generator-changing probe
- local phase gauge
- complex-conjugation ambiguity
- finite-shot Straddled
- serially correlated OutOfDomain

## 6. General response quotient

observation contract C = (probe perturbations, observables, times) に対し、

Phi_C(L)_{ji}(t) = Tr[O_j exp(tL)(Xi_i)]

を定義する。

L ~_C L' iff Phi_C(L) = Phi_C(L')。

出力は [L]_C。
individual jump operators を直接出力しない。
必要なら canonical traceless-jump gauge と固定 operator basis を明示し、
Kossakowski orbit または canonical superoperator class を返す。
