# 1. 最初に D2 を修復する必要がある

## 1.1 現在の D2 は提出形式が型不整合

`SPEC.md` は全報告が `EXPECTED_SCHEMA.json` に従い、許容誤差は `TOLERANCES.yml` から得ると規定しています。しかし、Unit D は D1–D4 を要求する一方、公開 schema と tolerance は A–C しか持っていません。`replications.yml` のコメントには D 用フィールドがありますが、正式な報告 JSON 契約には反映されていません。現状では第三者が「機械的に妥当な D2 報告」を作れません。 ([GitHub][2])

凍結済み v27.4 ファイルを直接書き換えるのではなく、次のように版を分離すべきです。

```text
reproducer/protocols/
  v27.4/
    abc-report.schema.json

  v32.1/
    unit-d-report.schema.json
    unit-d-tolerances.yml

    protocol-index.yml
```

`EXPECTED_SCHEMA.json` は現在「フィールド説明を値に入れた例示 JSON」であり、標準 JSON Schema ではありません。v32.1 では Draft 2020-12 等の実スキーマにして、pass 報告、failed 報告、必須フィールド欠落、無効な能力昇格を validator の負制御に含めるべきです。

## 1.2 D2 の「任意の連結グラフ」は強すぎる

Unit D2 は、独立に選んだ連結グラフについて

```text
B3 → gap support → clique complex → homology → links
```

を実行し、支持が真のグラフと欠0余0で一致することを期待しています。重み付きグラフも許可されています。 ([GitHub][2])

しかし、これは一般には成立しません。熱的相関

[
C=(I+e^{-A})^{-1}
]

は解析関数 (f(A)) なので、連結グラフでは通常、非辺にも歩道由来の非零相関が生じます。B3 の gap 選択が全グラフで直接辺を分離する定理はありません。

文書記載どおり、

* (\beta=1,\ h=-A)
* (B_{ij}=|C_{ij}|^2)
* (B_{ij}\ge \max B\cdot10^{-3}) を窓とする
* 窓内の最大対数段差が (\ln3) 以上ならそこで切る
* それ以外は窓全体を辺とする

と独立実装し、NetworkX graph atlas の連結非同型7頂点グラフを走査したところ、**853個中22個で非辺が余剰辺として残りました**。欠落は0、余剰のみでした。

最初の反例は次です。

```text
graph6: F}oXO
vertices: 7
true edges: 11
reported edges: 13
```

この例では真の辺と強い非辺の段差は

[
\log(0.01807046/0.00249751)=1.979>\log3
]

ですが、その後の非辺同士にさらに大きな尾部段差

[
\log(0.00249751/0.00020236)=2.513
]

があるため、「最大段差」規則は後者を選び、非辺2本を辺として残します。

これは外部再現失敗ではなく、**外部走行前に見つかったプロトコル反例**として記録すべきです。D2-v1 を黙って修正せず、`superseded_before_external_run` として保存するのが適切です。

## 1.3 D2 を static lane と response lane に分ける

### D2-S：静的 B3 lane

主張を次に縮めます。

> B3 が直接辺と非辺の間に、事前証明された分離マージンを持つグラフ族に対し、支持と下流位相を再現する。

必要な型は例えば次です。

```text
B3SupportMarginCertificate {
  min_true_edge,
  max_non_edge,
  unique_admissible_gap,
  frozen_gap_rule,
}
```

この lane は `StableEstimate` であり、任意グラフに対する exact readout ではありません。上の `F}oXO` は必須負制御として、正しく棄却させます。

### D2-R：応答 lane

外部 blocker の本命はこちらです。

```text
独立 h の生成
→ 独立 probe 準備
→ 密度時系列だけを readout に渡す
→ 曲率から |h_ij|² を復元
→ 支持
→ clique complex
→ β0..β3
→ vertex links
```

曲率則は任意の一体生成子に対する有限行列恒等式であり、静的 B3 の長距離相関混入を受けません。現行の D4 を単なる恒等式確認で終わらせず、トポロジーまで接続した end-to-end lane にします。 ([GitHub][3])

有限差分・測定ノイズ下では、

[
\min_{(i,j)\in E}|h_{ij}|^2 >
\text{curvature error bound}
]

を `ResponseSupportMarginCertificate` として要求します。非辺は単に「閾値以下」ではなく、信頼区間が0を含むかで裁定します。

D2-R の必須セルは最低でも次です。

* Kuhn (T^3,\ L\ge4)
* 16-cell (S^3)
* 中実 Kuhn 3-ball
* (T^3,\ L=3) の flag 破れ負制御
* 一つの独立生成 sparse weighted graph
* 高ノイズでの `Abstain(InsufficientObservation)`

成功しても解除されるのは **`spatial_topology_given_factorization` の独立性 blocker** だけです。E3 の因子分解、PRED-019、自然観測量、bridge law 登録は別問題のままです。D2 が対象としているのも現状は `GivenNodeFactorization` の能力です。

# 2. 主研究は OperationalAlgebra ではなく OperationalNet

現在の `OperationalAlgebra` 実装は、

```rust
pub struct OperationalAlgebra {
    pub preparations: Vec<&'static str>,
    pub interventions: Vec<&'static str>,
    pub measurements: Vec<&'static str>,
    pub compatibility: Vec<&'static str>,
}
```

という文字列リストであり、積、随伴、閉包、中心、可換子、交換子証明書を持っていません。正側はまだ名前だけです。 

さらに、**単一の閉じた演算子代数では因子分解を保持できません**。

site-local な完全操作集合も、mode-local な完全操作集合も、閉包を取ればともに大域代数 (B(\mathcal H)) を生成できます。どちらが site でどちらが mode だったかという情報は、閉包時に消えます。したがって必要なのは一個の algebra ではなく、

* どの primitive operation が存在するか
* どれが独立に address 可能か
* どの操作集合が一つの operational context を作るか
* どの交換子が0か
* どの準備と測定が対になっているか
* 各操作の provenance とコスト

を保持した **marked family of subalgebras** です。

名称は `OperationalNet` または `OperationalContextNet` が適切です。

```rust
OperationalNet {
    primitives: Map<OpId, PrimitiveOperation>,
    contexts: Set<Set<OpId>>,
    roles: Map<OpId, Preparation | Control | Measurement | Drift>,
    commutators: CertifiedIntervalMatrix,
    joint_addressability: IndependenceRelation,
    grading: Ordinary | FermionicZ2,
    provenance: Map<OpId, OperationalProvenance>,
}
```

準備、介入、測定は同じ数学的型ではありません。より厳密には、

* preparation：凸状態族または基準状態の tangent cone
* intervention：Lie/*-algebra を生成する control
* measurement：積に閉じる必要のない operator system
* compatibility：独立性・可換性の関係

として分離すべきです。

## 目標定理 A：Global-algebra erasure no-go

> 異なる tensor factorization に対応する二つの operational generator family が、同一の大域閉包代数 (B(\mathcal H)) を生成し得る。したがって大域代数の同型類だけから因子分解は識別不能である。

これは v31.4 の state-only no-go の、操作代数側での第二の no-go です。

## 目標定理 B：Marked operational recovery

primitive generator の非可換グラフを

[
\alpha\sim\beta
\quad\Longleftrightarrow\quad
|[O_\alpha,O_\beta]|>0
]

で定めます。次を仮定します。

1. 異なる未知ノードの局所操作は可換
2. 各ノード内の非可換グラフは連結
3. 各連結成分の *-閉包は full matrix factor (M_{d_i})
4. 全成分の join が対象 sector の (B(\mathcal H)) を生成
5. 観測誤差より非可換マージンが大きい

このとき連結成分と double commutant から

[
\mathcal H\simeq\bigotimes_i\mathcal H_i
]

を局所 unitary × ノード置換まで回復できる、という定理を目標にします。

ただし中心が非自明なら、無理に tensor product を返さず、

[
\mathcal H\simeq
\bigoplus_\alpha
\left(\mathbb C^{m_\alpha}\otimes\mathbb C^{n_\alpha}\right)
]

という superselection sector を返します。有限次元作用素代数における subalgebra と commutant の構造は、この direct-sum/tensor-block 形式を自然に与えます。 ([arXiv][4])

裁定は次の三値で十分です。

```text
一つの許容 gauge orbit
    → ExactUpToLocalUnitaryAndPermutation

複数の非同値 orbit
    → EquivalenceClassOnly

交換子・rank の区間が判定不能
    → Abstain
```

フェルミオンでは odd operator 同士に通常の可換性を要求してはいけません。`OrdinaryCommutation` と (\mathbb Z_2)-graded commutation を型で分け、現行の parity-even lane から開始するべきです。そうしないと Jordan–Wigner 順序を幾何として誤読する危険があります。

## 選択基準について

「最小 scrambling」や「最小相互作用」を全 tensor decomposition 上で直接最小化してはいけません。無制約なら eigenmode 分解を選び、v31.4 の疎性負制御と同じく幾何を消す可能性があります。

正しい順序は、

1. accessible primitive operations と独立 addressability に整合する factorization を列挙
2. その fiber 内でのみ、事前登録された動的 functional を tie-breaker に使う

です。

操作可能な観測量や相互作用が tensor product structure を規定するという大枠は既存研究にあります。また近年の operational mereology は、subalgebra と commutant の対、および短時間 scrambling 最小化を提案しています。QRN の新規性は一般原理そのものではなく、**識別可能性の fiber、棄却型、ノイズ証明書、holdout を含む構成的実装**に置くべきです。 ([arXiv][5])

# 3. 相関ホッピングは「曲率則が壊れるか」ではなく「何が読めるか」に再定式化する

v31.2 の法則は一体生成子で厳密、v31.5 では密度対角相互作用に厳密転移し、([H_{\rm int},n_j]\ne0) の相関ホッピングが未走査として残っています。 ([GitHub][3])

一般の基準状態差

[
\rho^+-\rho^-=2\epsilon A_\alpha
]

と測定演算子 (B_\beta) に対して、短時間応答は

[
R^{(1)}_{\beta\alpha}
=====================

# \frac{\dot b_\beta^+(0)-\dot b_\beta^-(0)}{2\epsilon}

i,\mathrm{Tr}!\left(B_\beta[H,A_\alpha]\right),
]

[
R^{(2)}_{\beta\alpha}
=====================

# \frac{\ddot b_\beta^+(0)-\ddot b_\beta^-(0)}{2\epsilon}

# -\mathrm{Tr}!\left(B_\beta[H,[H,A_\alpha]]\right)

\mathrm{Tr}!\left([H,B_\beta][H,A_\alpha]\right).
]

ここから明確な能力階層が出ます。

### 一階応答

(R^{(1)}) は (H) に線形です。情報完全な演算子基底上で (\mathrm{ad}_H) が分かれば、(H) は中心、すなわち full matrix algebra ではスカラー恒等項を除いて決まります。

### 二階応答

(R^{(2)}) は (\mathrm{ad}_H^2) を見ます。少なくとも

[
H\longleftrightarrow -H
]

を区別できません。密度だけに制限すれば、符号・位相・複数相互作用の交差項についてさらに大きな同値類が生じます。

したがって相関ホッピングを入れて密度曲率が裸の (|t_{ij}|^2) を返さなくなっても、それを単に「破れ」と採点してはいけません。曲率はその観測契約における**条件付き遷移率の Gram 核**を返している可能性があります。

短時間の準備・測定から Hamiltonian を線形逆問題として学習する方法自体は既存です。QRN が狙うべき新規部分は、観測契約ごとの kernel、gauge、因子分解依存性、および正しい棄却です。 ([ar5iv][6])

## 相互作用ハイパーグラフの正準定義

因子分解が確定した後、Hamiltonian を局所 Hilbert–Schmidt 条件期待値で

[
H=\sum_{S\subseteq V}H_S
]

と直交分解し、

[
w_S=|H_S|_F^2
]

を (S)-体相互作用の重みと定義します。

これは局所演算子基底の選び方には依存せず、局所 unitary で不変です。

* (|S|=1)：on-site
* (|S|=2)：graph edge
* (|S|=3)：correlated hopping 等の hyperedge
* (|S|\ge4)：高体相互作用

例えば (n_k c_i^\dagger c_j) は、(n_k=I/2+(2n_k-1)/2) と中心化すると、二体成分と真の三体成分に正準分離されます。

### 実験 lane

1. **density curvature**
   遷移率ハイパーグラフ。符号・位相は同値類。

2. **conditional density probes**
   補助ノードの ((2n_k-1)) bias を組み合わせ、Boolean Fourier/Möbius 反転で相互作用次数を分離。

3. **coherent parity-even probes**
   一階応答を用いて符号・複素位相を回復。情報不十分なら同値類を返す。

これにより候補3と候補5は、一つの研究プログラムになります。

# 6. VR と3多様体はこの順序で行う

## VR の先決事項

円の Vietoris–Rips complex がスケール増加に伴い (S^1,S^3,S^5,\ldots) 型を経ること、および winding fraction による分類は既知です。したがって次期の仕事は「1/3 法則の発見」ではなく、QRN の離散グラフ測地・有限標本・filtration 規約に対する厳密な bar 端点の導出です。 ([arXiv][8])

特に、

[
L/3-s
]

をそのまま全離散系の exact formula として凍結してはいけません。次を型に含めます。

```text
RipsConvention =
    DiameterLessThan
  | DiameterLessOrEqual

BarEndpoint =
    Open
  | Closed
```

さらに (N\bmod3) ごとの floor/ceiling を証明し、連続極限の (L/3-s) と離散 exact 値を分離します。

現在の実装は H1 persistence までで、大規模3Dでは brute force が blocker と記録されています。したがって H2 には sparse boundary reduction と column clearing を先に導入すべきです。 ([GitHub][9])

## レンズ空間を後回しにする理由

現在の

* (\mathbb Z_2) Betti 数
* 各頂点 link が (S^2) か
* (\beta_3)

だけではレンズ空間を分類できません。

例えば奇数 (p) の (L(p,q)) は、(\mathbb Z_2) homology では (S^3) と同じ Betti 数を持ち得ます。また、同じ (p) の異なるレンズ空間は integral homology も同じなので、(q) の識別には torsion linking form、Reidemeister torsion、または同等の分類不変量が必要です。レンズ空間の homeomorphism 分類自体が非自明な問題であることも既存の分類定理から明らかです。 ([arXiv][10])

能力を次のように分けるべきです。

```text
Closed3ManifoldWitness
IntegralHomologySignature
TorsionLinkingSignature
LensSpaceEquivalenceClass
HomeomorphismClass
```

最初から `LensSpaceIdentified` を返してはいけません。

# 7. 新規性を置く場所

既に知られている部分は明確に切り離すべきです。

* 操作可能な観測・相互作用が tensor product structure を規定するという原理は既知。 ([arXiv][5])
* subalgebra/commutant と minimal scrambling による operational mereology も既知。 ([arXiv][4])
* 短時間応答による Hamiltonian learning も既知。 ([ar5iv][6])
* 円の VR 1/3 遷移も既知。 ([arXiv][8])

QRN の新規性候補は次です。

1. **global algebra ではなく marked OperationalNet が因子分解を運ぶという、no-go と recovery の対**
2. **因子分解の fiber を gauge orbit／複数 orbit／棄却として機械裁定すること**
3. **因子分解と局所-unitary 不変 interaction hypergraph の同時識別**
4. **一階・二階・density-only・coherent の観測契約別 kernel の完全な相図**
5. **不可能性 recall を含む holdout と、外部再現能力を型で scope する方法論**

これなら、これまでの成果を単なる多数の toy computation ではなく、一つの識別可能性理論へ統合できます。
