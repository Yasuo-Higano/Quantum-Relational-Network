# 最も重要な修正

## 1. `QRN-Core` を4層に分割する

現在は、少なくとも次のものが「core」という名前の下で混ざっています。

| 層                        | 内容                       | 現在の状態                |
| ------------------------ | ------------------------ | -------------------- |
| `QRN-Kinematics`         | 量子状態、部分系・演算子代数、関係構造      | 旧 `QrnState` が部分的に実装 |
| `QRN-Dynamics`           | 状態を選び、発展させる原理            | 固有の原理は未定義            |
| `Background-QFT Adapter` | 外部計量と物質の結合、stress tensor | v26.8–v27.0で強く認証     |
| `QRN-Bridge`             | 状態・相関から計量、因果、重力を読み出す規則   | 仮説段階                 |

旧 core は、ガウスフェルミオン相関行列 `QrnState` と `QrnModel` から、幾何、エントロピー、物質、因果を読み出す構造です。これは C3 のtoy modelとして明確に限定されています。 ([GitHub][2])

一方、新しい§D.3は、BOND-A、中点変調、Belinfante (\lambda=-1/8)、Ward恒等式、殻積分などをcoreへ入れようとしています。しかし、これらはQRNの存在論的公理ではなく、

* 特定の格子離散化
* 外部計量へのsource coupling
* stress tensor operatorの改善
* 測定器の較正規則

です。

したがって、次の名称が正確です。

QRN-Matter-on-Background Adapter v1
QRN-Metrology Suite v1

`QRN-Core v1` という名称を残すなら、少なくとも上記4層を明示し、どこまでが完成し、どこからが未完成かを型と台帳で表現すべきです。

## 2. `RelationalNode` と `RegulatorSite` を同一視しない

これは第二十八期で最優先に潰すべき意味論上の型エラーです。

v27.0では「格子は regulator」と確定しました。一方、旧QRNではテンソル因子や相関網のノードが物理的実在として扱われています。 ([GitHub][1])

したがって、少なくとも次を別型にします。

```rust
struct RelationalNodeId(u64); // QRN存在論上の関係要素
struct RegulatorSiteId(u64);  // 数値離散化上の格子点
struct ContinuumPoint;        // 有効理論上の点
```

禁止すべき変換は次です。

```text
RegulatorSiteId -> RelationalNodeId
```

これは自動変換不能にし、変換を許すなら明示的な `BridgeLawCertificate` を要求します。

そうしないと、「格子由来の構造が観測された」ことが、いつの間にか「自然が量子ネットワークである証拠」に昇格します。

## 3. 外部時間と創発時間を分離する

初期公理A1は「時間は外部パラメータではなく、モジュラー流などから創発する」としています。しかし、旧 `QrnModel` は

```rust
fn evolve(&self, s: &QrnState, t: f64) -> QrnState;
```

という外部時間パラメータで動作しています。これは実装上ただちに矛盾というわけではありませんが、少なくとも現在は「シミュレーションの発展パラメータ」と「物理的に読み出された時間」が同じ `f64` に潰れています。 ([GitHub][3])

次のように分けるべきです。

```rust
struct EvolutionParameter(f64);
struct ModularParameter(f64);
struct OperationalClockReading(f64);
struct ProperTime(f64);
```

そして、

```text
EvolutionParameter -> ProperTime
```

もbridge lawなしでは変換禁止にします。

## 4. v0.7の「第一法則＝Einstein方程式」は修正が必要

これは今回の監査で見つかる最も重要な既存主張の修正点です。

`claims.yml` の `QRN-C0-001` は、

> エンタングルメント第一法則と線形化Einstein方程式の同値性は確立された研究成果
> Jacobson 1995 / Faulkner et al. 2013

としています。v0.7も、1+1次元自由フェルミオン鎖で (\delta S=\delta\langle K\rangle) を確認したことを「線形化Einstein方程式の直接検証」と位置づけています。 ([GitHub][4])

しかし、正確には次の区別が必要です。

* (\delta S=\delta\langle K\rangle) 自体は、基準状態近傍の密度行列に対する一般的な第一法則です。
* FaulknerらのEinstein方程式との同値性には、半古典的なホログラフィック双対、境界CFTの球領域、RT/Wald辞書などが必要です。 ([arXiv][5])
* Jacobson 1995は局所Rindler地平線に対する (\delta Q=T,dS) と面積エントロピーからEinstein方程式を導く研究であり、entanglement equilibriumの論文ではありません。 ([arXiv][6])
* entanglement equilibriumからの導出はJacobson 2015であり、小さな測地球、固定体積、真空エンタングルメントの停留性、共形場などの仮定を伴います。 ([arXiv][7])

したがってv0.7が実際に検証したのは、

> 1+1次元ガウス系におけるエンタングルメント第一法則とモジュラー核の数値再現

です。Einstein方程式は検証していません。

第二十八期の最初に、次を修正すべきです。

```text
QRN-C0-001:
  「一般的同値性」から
  「特定のホログラフィック／entanglement-equilibrium仮定の下での導出」
  へ限定する。

QRN-GRAV-v0.7:
  A3の直接証拠から、
  C1 instrument benchmark / modular-response benchmark
  へ降格する。
```

この修正は研究を弱めるものではありません。逆に、QRN固有のbridge lawがまだ存在しないことを正確に露出させます。

# composite graviton路線について

v27.0の現在の封印解除条件は、

* 相互作用による普遍 (q^2) 項
* Weinberg–Witten回避の明示

です。しかし、これは必要条件であって十分条件ではありません。 ([GitHub][1])

再開条件は少なくとも次まで拡張すべきです。

```text
CG0  regulator-independentなq²項
CG1  正の有限留数を持つ孤立spin-2 pole
CG2  ghost・余分なspin-0 modeなし
CG3  3-pointでのdiffeomorphism Ward identity
CG4  全物質と重力自己エネルギーへの普遍結合
CG5  soft-graviton limitの整合
CG6  Weinberg–Witten回避機構
CG7  kinematic nonlocalityまたは同等の構造
CG8  外部計量を入力せずに同じmetric sectorを得る
```

特に、局所的な微視的運動学から非線形・普遍結合する重力を創発させるには、何らかのkinematic nonlocalityが必要になるという一般的制約があります。単に二点関数に (q^2) が出ただけでは、重力にはなりません。 ([arXiv][11])

したがって、この路線は第二十八期前半では再開しないのが合理的です。

# 最終的な判断

第二十八期の本当の成功は、`PASS 1124` を `PASS 1300` に増やすことではありません。

成功条件は次の三つです。

1. **何がQRN本体で、何が既知QFTの測定器なのかを、コード上も文書上も混同不能にする。**
2. **QRN固有のbridge lawが存在するかを、失敗可能な形で問えるようにする。**
3. **第三者が独立に再現・批判できる最小単位を外部へ出す。**
