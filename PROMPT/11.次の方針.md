# 結論

**次の新規研究へ進む前に、v29.0 の裁定を再開封し、v29.1 を訂正版として出す必要があります。**

HOLD-3 の「相関長」計算に、判定を反転させる実装バグがあります。共通ライブラリの `linfit` は直線

[
y=a+bx
]

に対して **`(切片 a, 傾き b)`** を返します。一方、`xi_envelope` は

```rust
let (slope, _) = linfit(&xs, &ys);
-1.0 / slope
```

となっており、傾きではなく切片から (\xi) を計算しています。つまり現行コードが計算したのは

[
\xi_{\mathrm{code}}=-\frac1a
]

であり、本来の指数減衰長

[
\xi=-\frac1b
]

ではありません。([GitHub][1])

公表された HOLD-3 の値は B1=0.902、B2=0.755、B3=0.968 で、このうち B2 のみ窓外として棄却されています。([GitHub][2])
同じ入力・包絡・距離窓を独立実装し、まず誤実装値を約6桁で再現した後、傾きだけを正しく使用すると、次になります。

| 候補 | v29.0 の「ξ比」 |   正しい傾きによる減衰長 |     修正後の比 | 現行窓 `[0.8, 1.25]` | 全体裁定           |
| -- | ----------: | ------------: | --------: | ----------------- | -------------- |
| B1 |       0.902 | 4.261 / 4.305 | **0.990** | PASS              | HOLD-1 により棄却維持 |
| B2 |       0.755 | 8.506 / 9.010 | **0.944** | PASS              | **生存へ変更**      |
| B3 |       0.968 | 4.262 / 4.154 | **1.026** | PASS              | 生存維持           |

導出参考値 0.976 に対する偏差は、B1 約1.4%、B2 約3.3%、B3 約5.1%です。したがって、

* **B2 の「regulator 物性ゆえ棄却」という結論は成立しません。**
* **B3 の「導出期待から0.8%」という記述も成立しません。**

正式な数値は修正版 Rust バイナリの再走行で確定させるべきですが、既存の誤値を再現してから変更箇所を傾きに限定した再計算なので、判定反転の確度は高いです。

これは軽微な表示バグではありません。v29.0 文書の「二本生存・二本棄却」「B2 が regulator 物性を再発見」「B3 が期待値に0.8%一致」という中核的な物理解釈を変更します。([GitHub][3])

#[derive(Debug, Clone, Copy)]
pub struct LinearFit {
    pub intercept: f64,
    pub slope: f64,
    pub r_squared: f64,
}

#[derive(Debug, Clone, Copy, PartialEq, PartialOrd)]
pub struct DecayRate(f64);

#[derive(Debug, Clone, Copy, PartialEq, PartialOrd)]
pub struct CorrelationLength(f64);

impl TryFrom<LinearFit> for CorrelationLength {
    type Error = &'static str;

    fn try_from(fit: LinearFit) -> Result<Self, Self::Error> {
        if !fit.slope.is_finite() || fit.slope >= 0.0 {
            return Err("指数減衰を示す負の有限傾きではない");
        }

        let xi = -1.0 / fit.slope;
        if !xi.is_finite() || xi <= 0.0 {
            return Err("正の有限相関長を構成できない");

        Ok(Self(xi))

}

# 次に行うべき物理研究

## 第一課題：一様リングではなく、不均一一次元計量を再構成する

次の決定的な実験は 2D ではありません。まず **不均一な一次元背景**を通すべきです。

一様な Ring/Path は、隣接順と単一スケールさえ当てれば非常に高い R² が得られます。これは位相・順序のテストとしては有効ですが、位置依存する計量場の再構成ではありません。

推奨系は、同じ連続極限を持つ三つ以上の regulator で離散化した、滑らかな正値速度プロファイル (v(x)) を持つ一次元 Dirac 系です。

静的チャネルから空間距離を再構成し、動的チャネルは未使用の摂動源・未使用演算子について、

[
\tau(x,y)
\simeq
\int_x^y\frac{dx'}{v(x')}
]

を予言するようにします。

実験設計は以下です。

* 3 regulator × 4以上の格子間隔 × 3以上の質量
* 固定した物理長 (L)、物理質量、同一の (v(x))
* profile seed を train/validation/holdout で完全分離
* ラベル置換後に静的距離を再構成
* 静的距離を一切再調整せず、動的 arrival time を予言
* regulator 間距離歪みを continuum extrapolation
* 全体スケール・置換を除いた距離誤差を採点

例えば距離の一意性指標を

[
\Delta_\infty(d_1,d_2)=
\inf_{\pi,\alpha>0}
\max_{i<j}
\left|
\log
\frac{d_1(i,j)}
{\alpha,d_2(\pi i,\pi j)}
\right|
]

と定義できます。これにより「見た目が同じ」ではなく、置換・等長変換・全体スケールを除いた定量的な一致を評価できます。

これを通したとき、初めて「位相を超えた metric readout」と呼べます。

## 第二課題：単一観測量ではなく、operator-algebraic response atlas を作る

B3/B4 を統一する自然な対象は、局所部分代数 (\mathcal A_i) 間の静的・動的応答です。

[
K^{\mathrm{stat}}_{ij}
======================

\sup_{\substack{A\in\mathcal A_i,;B\in\mathcal A_j\
|A|,|B|\le1}}
\left|
\langle AB\rangle-\langle A\rangle\langle B\rangle
\right|
]

[
K^{\mathrm{ret}}_{ij}(t)
========================

\sup_{\substack{A\in\mathcal A_i,;B\in\mathcal A_j\
|A|,|B|\le1}}
\left|
\langle[A(t),B]\rangle
\right|
]

有限次元の局所演算子基底では、接続相関 superoperator や commutator superoperator の最大特異値として近似できます。

利点は明確です。

* 密度という任意の単一観測量に依存しない
* 対称性で保護されてゼロになるチャネルを回避できる
* 局所基底変換に対して不変な核を構成できる
* B3-COV と B4-DENSITY-FRONT を同一の応答 atlas の特定断面として位置づけられる
* 本来事前登録されていた QFI/BKM、retarded commutator と直接比較できる

次の候補競争は「MI 対 density」のような観測量名の競争ではなく、**局所代数間のどの不変ノルムが幾何を同定するか**という形に進めるべきです。

## 第三課題：一意性より先に、非一意性を探索する

状態だけから任意の幾何を一意に決める普遍写像は存在しません。最も単純には、同一の積状態は任意の非同型グラフ上に置けます。したがって

[
\rho \longmapsto g
]

を無条件に一意にすることは不可能です。

成立し得るのは、

[
(\rho,{\mathcal A_i},\text{state family},\text{responses})
\longmapsto
[g]_{\sim}
]

という、仮定つき・同値類への写像です。

次期には小サイズ系を全探索し、以下を積極的に探してください。

* 非同型グラフなのに同一または近接する静的核
* 同一静的核だが異なる動的前線
* 静的・動的の双方が近いが非等長な系
* factorization を変更しても同じスコアを得る系
* expander、small-world、非多様体分岐、ランダム正則グラフを manifold と誤認する系

「反例が見つからなかった」ではなく、探索領域・最小距離・衝突クラスを証明書として出します。単一のスペクトルなどから幾何が一意に決まらない現象には、非等長 isospectral 領域という既知の類例もあります。([arXiv][8])

理想的な第三十期の理論成果は、成功定理だけでなく、

> 静的単一状態だけでは不可能だが、局所代数と一定数の独立応答チャネルを加えると、指定された模型族では bi-Lipschitz 同値類まで同定可能

という **identifiability theorem / no-go boundary** です。

## 第四課題：その後に dimension-agnostic 2D

現在の再構成器は相互 top-2 グラフを作り、全頂点次数2の Cycle または次数1端点を持つ Path だけを幾何として認識します。これは一次元専用です。現状のまま 2D トーラスや円板を追加しても、アルゴリズムが構造上受け付けません。([GitHub][5])

2D の前に、次の dimension-agnostic pipeline を凍結する必要があります。

1. affinity (K_{ij}) の多重閾値 filtration
2. mutual-(k)NN または Vietoris–Rips/clique complex
3. persistent homology による Betti 数
4. neighborhood growth または diffusion による内在次元
5. vertex link による manifoldness 検査
6. graph geodesic と静的核の整合性
7. 閾値・(k) に対する安定領域

Persistent homology は filtration 中で長寿命な位相的特徴と短寿命ノイズを分離するための標準的枠組みです。([Ista Publish][9])

正例は少なくとも、

* torus: ((\beta_0,\beta_1,\beta_2)=(1,2,1))
* disk: ((1,0,0))
* sphere: ((1,0,1))
* cylinder: ((1,1,0))

とし、同時に random graph、分岐面、穴の近い二つのスケール、境界 edge mode を陰性・敵対対照にします。

```rust
pub trait BridgeCapability: sealed::Sealed {}

pub struct BridgeLawCertificate<C: BridgeCapability> {
    claim_id: ClaimId,
    evidence: EvidenceBundle<C>,

}
```

現状の証拠が将来発行できるとしても、上限は概ね
