# QRN 外部再現単位 (Reproducer) v1 — 仕様凍結 (v27.4, PROMPT/10 §6)

**目的**: 本リポジトリの主結果 3 単位を、**共有コードなしで**第三者が再実装・
再現 (または反証) できる形に固定する。成功しても失敗しても結果は公開され、
[CLAIMS.md](CLAIMS.md) の対応表に従って主張が昇格または降格される。

**再現者への約束**: 本仕様は結果を見る前に凍結されている (コミットハッシュで固定)。
仕様の曖昧さを見つけたら、それ自体が報告に値する成果である。

**独立外部再現と数える条件**: [NO_SHARED_CODE.md](NO_SHARED_CODE.md) の 6 条件
(機械可読版は [replications.yml](../replications.yml))。**同一作者・同一 AI・
同一数値カーネルによる別言語再実装は algorithmic diversity であり、独立外部再現
には数えない。**

**報告形式**: [EXPECTED_SCHEMA.json](EXPECTED_SCHEMA.json) に従う JSON 1 つ。
許容誤差は [TOLERANCES.yml](TOLERANCES.yml) (機械可読)。

## 単位 A — 有界領域のアノマリー全数分類 (整数厳密・最易)

**主張** (再現対象): 領域 D₁ (下記) の全数探索で、無矛盾カイラルスペクトルは
成分数 15 の標準模型 1 世代 **ただ一つ** (正準同値を除く)。

**領域 D₁** ([INPUTS/unit_a_domain.json](INPUTS/unit_a_domain.json) — 一次ソースは
`certificates/v62_domains.json` の run `R1_v31`):
- 表現: color ∈ {1, 3, 3̄}, weak ∈ {1, 2} (型は "1,1", "1,2", "3,1", "3b,1", "3,2", "3b,2")
- 超電荷: 整数 y = 6Y, |y| ≤ 9 (gcd 再スケールで既約化)
- 多重項 ≤ 5 個 (多重集合 — 同一多重項の反復可)・総成分数 ≤ 15
- 成分数 = dim(color) × dim(weak) の和

**条件** (全て厳密整数演算):
- A1: Σ y·d_w·T(R_c) = 0 ([SU(3)]²U(1); T(3)=T(3̄)=1/2 は 2T 整数化で扱う)
- A2: Σ y·d_c·T(R_w) = 0 ([SU(2)]²U(1))
- A3: Σ y·d_c·d_w = 0 (grav²U(1))
- A4: Σ y³·d_c·d_w = 0 ([U(1)]³)
- A5: Σ A(R_c)·d_w = 0 ([SU(3)]³; A(3) = −A(3̄) = 1)
- W: 弱二重項の数 (color 次元込み: Σ_{R_w=2} d_c) が偶数 (Witten)
- C: カイラル (多重項とその共役 (R̄_c, R_w, −y) が同時に現れない・完全実内容の禁止)
- F: 三因子全てに非自明に帯電した多重項が各因子に存在 (無菌状態の排除)

**正準同値**: 並べ替え・大域共役 (全多重項の共役 + y → −y)・U(1) 符号・gcd 再スケール。

**期待される答え** (厳密):
- 解 (正準形) は 1 個: 成分 15, 多重項 `["1,1:-6", "1,2:3", "3,1:-2", "3,1:4", "3b,2:-1"]`
- 正準形リストの SHA-256: `3017f659bf3b5e7b5c42f67099bf56a5915c552e70060468454804bb705c3a5e`
  (正準化・直列化の規約が違えばハッシュは合わない — その場合は多重項リストの
  集合一致で判定してよい。ハッシュ一致は追加の強い確認)

**過去のバグからの警告** (再現者への正直な情報): 弱二重項の次元の二重計上 (v5.2)
と群論係数の転記が既知の落とし穴。本リポジトリは独立 3 実装の byte 一致で守った。

## 単位 B — 半空間モジュラーハミルトニアンの規格化定数 λ (15 桁)

**主張** (再現対象): 3+1D staggered 自由フェルミオン半空間 (x 開放・単一絡み面)
のモジュラーハミルトニアンの NN ボンド規格化 λ は、方向依存の 2 定数

```
λ_x  = 1.185467287349258   ∈ [1.185462071698428, 1.185472502995920]  (証明付き区間)
λ_⊥  = 1.2294287643413095  ∈ [1.2293850463388851, 1.2294724848218264]
```

に収束する (区間は IEEE-754 仮定下の外向き丸め区間演算による厳密包含)。

**操作的定義** (完全な導出は paper/modular-bw-full.md = 凍結原稿, Zenodo
10.5281/zenodo.21541851):
1. 3+1D staggered 半空間の相関行列 C_A は横運動量 (k_y, k_z) ごとに、質量
   μ(k_y,k_z) = √(cos²k_y + cos²k_z) の半無限 1D staggered 鎖 2 本に厳密分解する。
2. 半無限 1D 鎖 (hopping −1/2, staggered 質量 ±μ) の entanglement Hamiltonian は
   H_EH = 4κK(κ′)·T で厳密 (Eisler 2025, arXiv:2410.16433; κ = 1/√(1+μ²))。
   ⇒ 1D の BW 規格化は g(μ) = (2/π)·κ·K(κ′) = 1/AGM(1, √(1+μ²))。
3. λ は BZ 平均: 1/λ_x = ⟨g(μ)⟩_BZ, 1/λ_⊥ = ⟨2cos²k_y · g(μ)⟩_BZ
   (⟨·⟩_BZ = (2π)⁻² ∫∫ dk_y dk_z)。
4. **独立再現の推奨経路**: 式 3 の閉形式評価だけでなく、有限鎖 (N ≥ 96) の
   モジュラー核の直接対角化から λ を直読みして閉形式と突き合わせる
   (本リポジトリの直読み値 1.185468(2) — 収束は 1/N⁴)。

**警告**: f64 のモジュラー核は κ ≤ 32.2 で飽和する (固有値クランプの床)。
深部モードには拡張精度が要る。λ を「温度」と解釈しないこと (方向依存の
regulator 規格化 — 本リポジトリで棄却済みの解釈)。

## 単位 C — Dirac stress-tensor 真空偏極の連続極限 universality

**主張** (再現対象):
1. **解析 oracle**: 質量 0 の 1 Dirac フェルミオンの TT (spin-2, D チャネル)
   one-loop 真空偏極の q⁴ln q² 係数は 16π²·A = −1/10 (厳密有理数)。
   スペクトル密度は ρ_D(s) = s²/(160π²)。スカラー (taste-singlet) 和則は
   ∫ρ_θ/s³ ds = 1/(80π²) (質量非依存)。
2. **格子 universality (PRED-016 の再現)**: staggered (2-taste)・空間 Wilson
   (1-flavor) の二離散化で BOND-A 型ボンド変調 source の繰り込み後 TT form factor
   を測ると、連続極限 (a → 0, 固定 m_phys = 0, q_phys) で 4 比
   (A^stag_D/2A, A^stag_X/4A, A^Wil_D/A, A^Wil_X/(A/2); A = −1/(160π²)) が
   全て 1 に収束する — 中心 |比 − 1| ≤ 1%・系統 (全域 vs 尾部窓の外挿差) ≤ 0.5%。

**操作的定義** (完全な構成は paper/grav-vacuum-polarization-spec.md = 実装前凍結
仕様; 較正記録は instruments.yml):
- source = ボンド変調 (1+h)^{−1/2} (scheme BOND-A)・q⁴ln q² 係数は null 結合
  (Σw = ΣwQ² = ΣwQ⁴ = 0) で抽出・外挿モデルは観測量の漸近形から導出
  (stag: {1, a²ln(1/a), a²} / Wil: {1, a, a²})。
- ladder: a = 0.5 → 0.022 級、Q 窓 [0.15, 0.9]。

**警告**: bare 係数 (c₁, c₂) の一致は要求されない (regulator 量)。q² 係数を
Newton 定数と呼ばない・1/χ を伝播関数と呼ばない (禁止解釈 — instruments.yml)。

## 提出方法

報告 JSON (EXPECTED_SCHEMA.json 準拠) を、公開リポジトリの URL・コミットハッシュ・
実装言語・実行環境とともに issue で提出する。**失敗・不一致も同じ形式で提出する**
(不一致は本リポジトリの主張の降格材料であり、それ自体が寄与である)。
受理された報告は replications.yml に登録され、6 条件を満たすものだけが
external replication として計数される (それまで計数は 0 のまま維持される)。
