## 1. 恒等式 (Schrödinger 規約 ρ(t) = e^{−iHt} ρ e^{iHt} — v31.2 と同一)

基準状態対 ρ± = ρ₀ ± εA_α・測定 B_β に対し:

```text
R⁽¹⁾_βα = (ḃ_β⁺(0) − ḃ_β⁻(0))/(2ε) = −i·Tr(B_β [H, A_α])
R⁽²⁾_βα = (b̈_β⁺(0) − b̈_β⁻(0))/(2ε) = −Tr(B_β [H,[H,A_α]]) = Tr([H,B_β][H,A_α])
```

**[L0]** dim 8 の一般エルミート H で、時間発展 (複素 Taylor expm) + 4 次 stencil の
測定値が両式と一致 (非自明対 4+4 本, max rel 偏差 2.0e-10 / 1.5e-10)。
ε ∈ {0.02, 0.10} の差分商は 8.9e-15 で一致 — **恒等式であり線形応答近似ではない**
(トレースは ρ に線形)。

## 2. 能力階層 (機械化)

| 次数・契約 | 読めるもの | 読めないもの (同値類) |
|---|---|---|
| R⁽¹⁾ × 情報完全基底 | **H を中心を除いて一意** ([L1]: 15×15 線形逆問題で ‖Ĥ−H‖/‖H‖ = 1.2e-16) | スカラー恒等項 (H + cI の R⁽¹⁾ 差 = 厳密 0) |
| R⁽²⁾ (全観測) | ad_H² | **H ↔ −H (厳密: max 差 0.0)** — 一階は符号分離 (R⁽¹⁾[−H] = −R⁽¹⁾[H]) |
| R⁽²⁾ × 密度のみ | \|h_ij\|² (遷移率 Gram 核) | **ring の磁束 θ (密度核の θ 差 = 厳密 0)** — coherent 一階 (電流観測) は分離 (−1.0000 vs −0.9211) |

**[L2] no-go の対**: R⁽²⁾ は ad_H の偶関数なので H ↔ −H を原理的に区別しない。
密度制限はさらに粗い — 3 モード JW ring の磁束は density-only kernel に**厳密に
不可視** (v31.2 曲率が \|h_ij\|² = t² を返すため)。coherent lane (電流) の一階が
分離する。**「破れ」ではなく、観測契約ごとに読める同値類が違う** — 相関 hopping
(v32.5) はこの枠で採点する。

## 3. 保存則と PSD [L3]

- 数保存 H に対し B = N̂ の応答は**全次数で厳密 0** (max 1e-13 未満) — 粒子数保存が

- 応答 Gram 核 K_αα' = Tr([H,A_α]†[H,A_α']) は **PSD** (λ_min = 0.0, 情報完全 15
