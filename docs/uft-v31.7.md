# QRN v31.7 — 開放境界 regulator 不一致の機構分類

(7 検査 PASS)
**位置づけ**: PROMPT/12 第八版 — v29.4b の唯一の不成立 (hold-12 開放鎖 R-A×R-C
到着時刻一致 0.2328 > バー 0.23) の機構を確定する。**バーは変更しない・不成立の

## 1. 設定

開放鎖 (N_phys = 48)・一様 v = 1・staggered 質量 m = 0.4。R-A = 単鎖 staggered、
R-C = Wilson (r = 1, 実ゲージ 2 成分) — v29.4b と同じ構成を a = 1, ½, ¼ に細分。
到着時刻 τ は probe C₀ = I/2 + εP_s の密度前線 (伝播子 |G(t)|² で厳密評価 —
状態非依存)。v̂ は窓 5 セルの線形フィット。

## 2. 確定した機構

| 検査 | 結果 |
|---|---|
| [B0] 分散アンカー | bulk 前線速度比 \|v̂_A/v̂_C − 1\| = 29.7% (a=1) → 6.7% (½) → 2.7% (¼) — **O(a) で消える** |
| [B1] 誤差分解 (a=1) | τ バイアスのデトレンド残差: 境界 7.9 vs bulk 4.1 (**1.9×**) — a=1 の不一致は**分散形状差 + 境界の複合** (境界「だけ」ではない) |
| [B2] a 掃引 | 端の残差振幅 7.9 → 1.08 → 0.47 (**~O(a) で消失**)・スパンは**物理 ~14 セルで一定** (反射前線の尾) |
| [B3] 反射位相 | 実効壁位置 δ_A = +0.50 vs δ_C = +1.10 (**Δδ = 0.60 格子**, 整合 k ≈ 0.8–0.9) — 機構の実体 |
| [B4] 境界 LDOS | 自 bulk 参照の境界固有偏差: 0.024 (端) → 0.005 (深さ 6–8) — 境界集中 |
| [B5] 到着バイアス | 端 1 物理セルの τ バイアス: a=1 で 7.3 → a=¼ で 0.45 (**×0.06**) |
| [B6] 裁定 | **振幅消失型 reflection artifact** — universality class 差ではない |

**機構の要約**: R-A と Wilson R-C は開放端の**実効壁位置が 0.6 格子ずれる** ([B3] —
自己共役境界条件の regulator 差の現れ)。このずれが反射前線に刻まれ、**物理スパン
~14 セルの反射尾**として τ プロファイルに現れる ([B2])。振幅は ~O(a) で消える
([B2][B5]) — つまり**連続極限に残る成分はない** (異なる境界普遍類ではない)。
a = 1 (HOLD-5 の設定) では bulk 分散形状差も同オーダで加算され ([B1])、hold-12 の
0.2328 の尾を作った。

## 3. v29.4b の裁定への含意 (変更しない)

- hold-12 の**不成立の記録・バー 0.23 は不変** — 「後から機構が分かったから成立」に
  しない (v31.0 絶対禁止 10)。
- v29.4b の記録「val の位相層化不足」と本機構は整合: 開放鎖の val 標本が反射尾の
  regulator 系統を過小評価していた。
- **次期 holdout への設計入力**: 開放境界系では (i) 反射尾セル (端から前線幅) を
  scope から型で除くか、(ii) 境界込みの別バーを凍結するか、(iii) a 掃引で
  振幅消失を確認する連続極限 lane を足す — のいずれかを実行前に選ぶこと。

## 4. 正直な残高

- 一様 v のみ (hold-12 の実場は重み場つき) — 機構は壁位置 + 反射なので一様系で
  同定可能と判断したが、場との複合効果は未走査。
- 質量 1 点 (m = 0.4)。m 掃引・源位置多点は [B5] の 1 点 collapse のみ。
- 振幅の消失次数は 7.9/1.1/0.47 から O(a)–O(a^1.5) — 厳密な冪の同定は未実施。
- 開発記録: 統計量の参照系を 3 回誤った — (i) 局所 v̂ = 1/Δτ は到着離散化ノイズで
  破綻 → 窓フィット (ii) a=1 では bulk 自体が違う → 規格化/デトレンド (iii) LDOS は
  bulk DOS 差 ~0.2 が支配 → 自 bulk 参照。「regulator 比較は常に自分の bulk を
  参照してから境界を見る」を教訓として記録。
