## 1. 中心定理 (本版の発見): 曲率則は密度対角相互作用に厳密転移する

spinless t-V 鎖 H = −Σt(c†c+h.c.) + VΣnn (厳密対角化, N=10) で、v31.2 の密度曲率則

```text
(n̈_j⁺ − n̈_j⁻)(0) / (4ε) = |t_{ji}|²   — V ∈ {0, 2, 4} で 1.000000000000 (≤ 1e-12)
```

**V に厳密に依存しない** ([N3])。理由は 2 つの厳密な消滅:

1. probe 積状態の差 ρ⁺ − ρ⁻ = 2ε(2n_i − 1) ⊗ (I/2)^{⊗(N−1)} は **ε に厳密線形**
   (積の他因子が相殺)。
2. V 項は密度対角 → [H_V, n_j] = 0、かつ二重交換子の交差項 [H_V, [H_t, n_j]] は
   占有基底で非対角 → **対角 probe 差とのトレースで厳密に消える**。

相互作用は t³ 以降の時間展開にのみ入る — 測定 lane (V=2, 実時間 ED 発展, 密度時系列
のみ, Richardson) も rel 1.3e-8 で復元 ([N4])。**応答読み出しは Gaussian 資格の外へ
拡張できる最初の候補** (密度対角相互作用のスコープ内で)。

## 2. 大域 oracle は転移しない (Gaussian-only と確定)

- Gaussianity witness (密度-密度 Wick 残差): V=0 で 1.5e-14 → V=4 で 0.14 と単調増大
  ([N1])。
- V=2 熱的 C に oracle を適用: witness 4.2e-2 > 凍結バー 1e-8 →
  **NonGaussianDomain 棄却** ([N2])。棄却の物理的理由も機械記録: parent K が hopping
  支持の外 (非隣接) に max 0.032 の成分を持つ — 棄却しなければ**偽の長距離結合を
  物理と誤読**する。
- 凍結バー holdout ([N7], 未使用セル V=1.5 open / V=3.0 pbc): oracle 棄却・応答復元
  (5.9e-9 / 1.9e-8) — 両セル生存。

## 3. 静的 B3 の非 Gaussian 障害 ([N5])

| 状態 | B3 支持 |
|---|---|
| 熱的 β=1, V=0.5 | ring 厳密 (10 辺) |
| **熱的 β=1, V=4** | **破れ — 20 辺 (ring + 全次近接)**: CDW 前駆の同副格子相関が偽の辺を作る |
| GS V=0.5 (臨界 LL) | ring (N=10 では生存) |
| GS V=4 (CDW) | ring — ただし対蹠相関 0.13 = 最小 bond の 66% (margin 縮小を記録) |

v29.6 [T2b] (臨界 GS の境界増強)・v28 B1 境界増強に続く**静的読み出し障害の非 Gaussian
版** — 強結合熱的状態で静的核は幾何を誤読し、応答 lane は同じ状態領域で無傷 ([N3] が
V=4 を含む)。

## 4. 系列 B — Z2 拘束系 (lib::Z2GaugeRing): 位相のみ転移

Z2 格子ゲージ + staggered フェルミオン環 (L=8, 拘束を解いた基底) で、対角再重み付け
probe による曲率読み出し ([N6]):

- **支持 (位相) は厳密に転移** — 非 bond 応答は 7.4e-17 (厳密 0)。
- **重みは拘束による系統偏差 14.3%** — 機構 = probe の積構造が半充填 sector 固定で
  壊れる (背景相関 |⟨n₀n₁⟩_c| = 3.6e-2)。

スコープ確定: 「Z2 拘束系では位相のみ転移・定量重みは拘束補正が必要」。

## 6. 正直な残高

- 厳密転移のスコープは**密度対角相互作用** — 相関ホッピング等 [H_int, n_j] ≠ 0 の
  相互作用では交差項が消えない (未走査 — 破れの候補として次期へ)。
- witness は密度-密度 Wick 残差 — 一般 4 点残差・高次キュムラントの witness 階層は
  最小実装 (密度対角の検出には十分)。
- ED は N ≤ 10 — 熱力学極限のスケーリングは未走査。
- 凍結バーは同一バイナリ内宣言 (コミット分離の凍結は HOLD-7)。
- 初期予想 2 件の訂正を記録: (i)「CDW GS が B3 を破る」→ N=10 では生存 (margin 66% に
  縮小)、破れは**熱的** V=4 に出た。(ii) Z2 の重み偏差 5% 想定 → 実測 14.3%。
