## 2. 失敗の解剖 — 候補固有 1 件と採点器の共通モード 2 件

**(a) B1 × HOLD-1 = 候補固有の真の失敗 (棄却は維持)**。開放端の MI は端点対
(0,1)/(99,100) で橋判定則 (相互 top-1 + 3× 支配) を発火させた — 端点は唯一の強い
相手しか持たず、境界増強された MI(0,1) が第 2 位を 3 倍以上支配する。**B2/B3 は
同じ系・同じ凍結パイプラインで Path 101・隣接 100% を通過**しており、これは
パイプラインの故障ではなく **MI 核の境界増強という候補固有の性質**である。
凍結規則 (failed_bridges_rejected_not_tuned) により B1 は棄却のまま。

**(b) HOLD-3 の ξ 比 = 採点器の共通モード故障 (候補の性質ではない)**。3 候補が
同型に失敗した (比 0.70/0.53/0.80 — 全て下方) のは器械の指紋 (v26.4 の教訓)。
原因は v28.2 で宣言した ξ 推定則「偶数距離 d ∈ {4,…,20}」の設計ミス:
staggered 鎖では偶距離 = **同副格子**であり、半充填の C(偶 d) は m → 0 で恒等的に
零 (C(d) = sin(πd/2)/(πd)) — 質量が生む抑制チャネルだけを拾う。一方 Wilson
(2 成分/site) に副格子構造はなく通常チャネルを拾う。**推定則が二つの系で別の
チャネルを比較していた** — これは「同一巨視幾何」の検査として ill-posed
(PRED-014 の「s→0 は固定 q で ill-posed」と同型の判定変数の欠陥)。

**(c) B4 × HOLD-4 開放鎖の 0 点 = 採点インフラの設計不備**。宣言した距離供給が
「B1 の再構成 path」だったため、B1 の H1 棄却に連動して B4 の検査が採点不能に
なった — 候補 B4 自身の性質を測っていない。

## 3. 修正条項 (本コミットで凍結 — 再採点 v28.3 の走行より先)

PRED-016 の先例 (spec §12.9 — 採点器の修正条項を実装・走行より先にコミット、
1 回限り、的とバーは不変) に従う。**候補・核・パイプライン・判定バーは一切
変更しない。**

- **修正条項 1 (ξ 推定則の副格子盲目化)**: ξ は距離 d ∈ {3, 4, …, 20} (全整数)
  ごとの**上包絡** y_d = ln(max_{対 at d} w) を線形フィットして −1/傾き とする。
  上包絡は各距離で支配チャネルを拾うため、副格子抑制チャネルの混入が両系で
  対称に消える。導出による期待値 (バーではなく文脈): staggered の支配減衰
  κ_s = arsinh(m·a) = 0.049979、Wilson は k = 0 ギャップ m の伝達減衰
  κ_w ≈ ln(1 + m·a)-級 = 0.0488 — w が |C|^p 型なら比は p に依らず
  κ_w/κ_s ≈ 0.976 (窓 [0.8, 1.25] の中央付近)。バーは不変。
- **修正条項 2 (HOLD-4 開放鎖の距離供給則)**: 距離供給は「HOLD-1 を通過した
  空間候補のうち候補番号最小のものの再構成 path」(B1 → B2 → B3 の順) とする。
  B4 の検査は B4 と独立に較正された距離を使うべきで、特定候補の棄却に連動して
  採点不能になる設計は候補の性質を測っていない。
- **不変条項**: 凍結節 (核・パイプライン・全バー) は v28.1 のまま。v28.3 は
  凍結節 SHA-256 一致に加え、**修正と無関係な全セル (H1・H2・H4 リング) の
  裁定が第一採点と一致することを回帰アンカーとして機械検査する。**
