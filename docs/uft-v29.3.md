## 1. 新しい器械 (凍結節 v30)

- **HOLD-5 生成器**: v(x) = 1 + Σ A_k exp(−((x−c_k)/w_k)²) (v29.2 凍結仕様の実装)。
  train seed 4 本は公開定数 (SECRET 開示時に第三者が sha256 で検証可能)。
- **B5-QFI (BKM 核)**: 数保存 Gaussian の Fock 行列要素の厳密公式
  **ρ_{S'S} = det(1−G)·det(K[S'|S]), K = G(1−G)⁻¹** で 2 ノード RDM (≤16×16) を
  構成し、‖ρ_ij − ρ_i⊗ρ_j‖ を BKM 重み c(λa,λb) = (λa−λb)/(ln λa−ln λb) で測る。
  [M0a] 恒等検査: 1/2 モード解析形・トレース 1・一体縮約が G に戻る・BKM 対称性。
- **B6-COMMUTATOR**: ⟨[n_j(t), n_q]⟩ = 2i·Im(P_{qj}·(P†Ce_q)_j) の閉形式で
  retarded 前線 (状態依存) と、|P_{qj}(t)| の**運動学的円錐** (状態非依存) を
  別チャネルとして併走。
- **Wilson の実化**: サイト非依存の基底回転 T = diag(1, i) で σ₁ → σ₂ とすれば
  1D Wilson は**実対称** — hopping ブロック [[−rt, −t],[t, rt]] (t = v/2)。
  [M0b] 一様極限の分散照合 max|ΔE| = 3.5e-14。
- **順序付きパイプライン reconstruct_v30** (§2 の教訓から): まず**橋なし**の
  相互 top-2 で再構成し、幾何が出れば採る。失敗時のみ v29 凍結節の橋つき再構成に
  フォールバック (TFD 型用)。橋の導入は必要になったときだけ — Occam。

## 2. 設計区画の教訓 (train で発見・修正 — holdout 前なので調整可)

1. **Wilson ブロック係数の 1/2 二重掛け** — [M0b] の解析分散照合が max|ΔE| = 0.5
   で即検出 (器械の恒等検査を系構成に必ず付ける、の再確認)。
2. **B1/B5 が不均一計量の強ボンド対を「橋」と誤検出** — v(x) の山で局所増強された
   情報系核 (MI・QFI) が v29 橋判定 (3× 支配) を発火し位相を壊した。これは
   **v28 の「B1 境界増強」のバルク版** — 情報系核の局所増強と橋判定の衝突は端
   だけの現象ではない。順序付きパイプライン (橋なし優先) で解決 — B2/B3-COV は
   どちらのパイプラインでも通る (応答系核は増強が穏やか)。
