**Date**: 2026-07-30

**位置づけ**: 現行の再構成器 (凍結 v29/v30 節) は相互 top-2 の Cycle/Path 認識 =

## 1. pipeline (PROMPT/11 の 7 項目の実装)

```text
状態 → B3-COV 核 K_ij
  1. 頂点適応 gap 則: 各頂点 i は「m 位/(m+1) 位の親和度比 ≥ 1.5 を満たす最大の m」
     を近傍数に選ぶ (絶対スケールガード w ≥ 0.15·w(1位) つき)。
     段差が一つもない頂点が過半 → 裁定保留 (縮退カーネルで幾何を捏造しない)
  2. 相互選択グラフ → clique complex (単体は 3-simplex まで)
  3. Z2 係数 homology (境界行列の列簡約 — 自作, 標準 persistence 算法の固定複体版)
     → Betti 数 (β0, β1, β2)
  4. 殻計数 S(r) ~ r^{d−1} による内在次元 (球計数 N(r) は小 r のオフセットで
     傾きが潰れる — 殻版は格子で厳密)
  5. vertex link の多様体性 (閉曲面: link ≅ 円周 / 境界: 弧 / それ以外: 非多様体)
  6. graph geodesic と核の順位整合 (Spearman)
  7. 探索窓 kmax ∈ {7..10} の全会一致 (profile が窓に依らない = 安定領域)
```

エンジン検査 [T0]: C8 = (1,1,0)・充満 K4 = (1,0,0)・2×C6 = (2,2,0)・三角化
T² = **(1,2,1)**・icosphere S² = **(1,0,1)** — 全て既知値と一致。内在次元 [T1]:
dim(C24) = 1.000・dim(T² 8×8) = 2.000 (厳密)。

## 2. [T2] 正例 — 状態から end-to-end (資格状態族 = 熱的 Gaussian, β t = 1)

| 系 | β 期待 | β 実測 | 曲面裁定 | 隣接復元 | dim |
|---|---|---|---|---|---|
| torus 8×8 (三角格子) | (1,2,1) | **(1,2,1)** | closed ✓ | 欠 0 余 0 | 2.00 |
| cylinder 8×6 | (1,1,0) | **(1,1,0)** | boundary ✓ | 欠 0 余 0 | 1.75 |
| disk 8×7 | (1,0,0) | **(1,0,0)** | boundary ✓ | 欠 0 余 0 | 1.58 |
| sphere icosphere-1 (42 頂点) | (1,0,1) | **(1,0,1)** | closed ✓ | 欠 0 余 0 | 1.65 |

全 4 種で窓 4 つの全会一致。座標・隣接・次元はどこにも入力していない —
熱的 Gaussian 状態の相関だけから、トーラスの 2 つの非可縮ループも球の空洞
(β2 = 1) も読み出された。**1 次元専用だった幾何読み出しが初めて次元を跨いだ。**

## 3. [T2b] 発見 — 臨界半充填 GS は局所グラフ抽出を破る (v28 境界増強の 2D 版)

資格に至る過程で、当初の状態族 (半充填**臨界**基底状態) では正例が壊れることを
突き止めた (記録のみ — ゲートは熱的状態族):

| 系 | 臨界 GS の裁定 | 欠/余辺 | 機構 |
|---|---|---|---|
| torus | (1,2,1) closed — 無傷 | 0/0 | 境界なし・並進不変 |
| cylinder | not-surface | 0/**32** | **開放端の境界増強相関**がリム沿いの距離 2 対を近傍に昇格 |
| disk | (1,**6**,0) | **6**/2 | 境界増強 + コーナー系統で辺を取りこぼし偽の穴 |
| sphere | (1,**6**,1) | 0/**6** | **Friedel 共鳴**が特定の角距離対を増強 (icosahedral 軌道の 6 対) |

これは v28.2 で B1 (MI) を holdout 棄却させた「境界増強」の 2 次元版の独立再発見
であり、v29.5 [C4] (無情報状態は幾何なし) の裏面 — **状態族の仮定は
identifiability の実質的な前提である** (ギャップ相関 = 読める / 臨界 = 長距離
構造が局所抽出を破る)。gap 則の設計でも 2 つの失敗モードを機械同定した:
argmax 則は境界の不均一な真近傍を取りこぼし (偽の穴を列生成)、無ガードの
最大 gap 則は球の遠方偶発段差を拾う (偽辺) — 確定則は「スケールガード付き
最大 gap」。β t = 2 でも 2 穴円板の隘路 (穴と鈍角コーナーの間の幅 2 の帯) が
距離 2 対 (9,8)-(11,10) を相互昇格させた — β t = 1 で距離 2 相関は O(β²) に
潰れ根治。

## 4. [T3] 敵対対照 — 幾何を捏造しない

- **random 3-正則 (n=64)**: not-surface (β1 = 33 の非多様体) — 曲面と誤認せず。
- **分岐面 (3 シート共有線)**: not-surface — spine の link が theta 型で検出。
  (開発記録: 2 シートの貼り合わせは**曲がった平面 = 多様体**になってしまう —
  本物の分岐には ≥ 3 枚が要る。)
- **大小 2 穴の円板 (1 サイト + 7 サイト穴)**: **β = (1,2,0)・boundary** —
  両穴を分離して計数。
- **Petersen**: not-surface (適応 k = 3 がグラフを正しく復元 → 三角形なし →
  link 検査で棄却) — **v29.5 [C7b] の誤認 (k=2 固定 + fallback 捏造) の構造的
  解決**。
- **K7**: 全窓が縮退保留 (4/4) — 段差のないカーネルに幾何を主張しない。

## 5. 限界と次段 (v30.0 への入力)

- 資格は**設計区画** (正例・対照を見ながら則を確定した) — 検証力はない。新鮮な
  holdout (未見の位相・v(x) 変調つき 2D 計量) は v30.0 の scoped certificate
  設計と併せて行う。
- 穴スケールの**寿命分離** (persistence barcode) は clique-順位 filtration では
  現れない (グラフの穴は不滅バー) — 計量 Vietoris–Rips (三角形を大スケールで
  充填) の実装は次段。
- 臨界状態の 2D 読み出しは open problem として登録 (境界増強・Friedel 共鳴に
  頑健な核 — PROMPT/11 第二課題の不変ノルム核が候補)。
- β2 の読める最小系が icosphere-1 (42 頂点) — より大きい球・高 genus (double
  torus) は未試験。

## 6. 開発記録

- 状態族の選択が本版の中心的学び: 「臨界 GS で試す → 3/4 破れ → 破れの機構
  (境界増強/Friedel) を診断 (欠/余辺の座標まで機械同定) → ギャップ状態族で資格 +
  臨界の破れを [T2b] に記録」— 破れは削除せず、発見として保存した。
- 2 シート分岐面が多様体になる幾何の初歩を検査が教えた (敵対対照の設計自体が
  検査で鍛えられた)。
- 隘路の距離 2 増強 (2 穴円板, β t = 2) は診断印字 (欠辺/余辺の座標) がなければ
  盲目の反復になっていた — 「差分は座標まで印字してから直す」を器械設計の規約に。
