## 1. 事前登録計量

raw affinity を計量と呼ばない。登録した計量は **辺長変換 ℓ_ij = 1/√ŵ_ij + 最短路閉包
(Dijkstra)** — 閉包が三角不等式を構成的に保証する (対称・非負は構成から)。
ŵ = 曲率則の測定重み |t_ij|²。

## 2. 3D homology engine (∂₄ 必須) — [V0][V1]

- β₃ = dim ker ∂₃ − rank ∂₄。**K5 anchor が im ∂₄ の必須性を機械化**: clique complex
  = 中実 Δ⁴ は (1,0,0,0) だが、4-simplex を落とすと ∂Δ⁴ = S³ の (1,0,0,1) に化ける。
- anchors 全通過: ∂Δ⁴ (1,0,0,1) / 16-cell (1,0,0,1) / **Kuhn 三角化 T³ L=3 (1,3,3,1,
  162 tets)** / 中実 Kuhn 立方体 (1,0,0,0)。
- **3-manifold link 分類**: T³ 全 27 頂点 link = S²・中実立方体は内部 1 (S²) +
  境界 26 (D²)・1 点接着 tet 対は not-manifold (特異) — Betti 数の一致だけでは
  3 多様体性を主張しない。

## 3. from-state 3D end-to-end — [V2]

熱的枠の曲率則測定 lane (時系列のみ・状態非依存) → 支持 → clique complex →
(β₀..β₃) + link 多様体性:

| 系 | 支持 | β | link 裁定 |
|---|---|---|---|
| T³ (Kuhn L=4, 64 頂点) | 欠0余0 | **(1,3,3,1)** | closed ✓ |
| S³ (16-cell, 8 頂点) | 欠0余0 | **(1,0,0,1)** | closed ✓ |
| 3-ball (中実 L=2, 27 頂点) | 欠0余0 | **(1,0,0,0)** | boundary ✓ |

**幾何読み出しが初めて 3 次元を跨いだ** (v29.6 の 2D → 3D)。

**発見 (flag 性の破れ)**: T³ L=3 では周期軸線 (0-1-2-0) が巻き付き 3-クリークを作り
**clique complex ≠ 三角化** (β = (1,0,63,1) に化ける) — L ≥ 4 で flag 性が回復する。
最小周期系の clique 読み出しには系サイズ下限がある (v29.5 Petersen 縮退と同族の
教訓 — 幾何が小さすぎると読み出し複体が別物になる)。

## 4. 計量 VR persistence — [V3]–[V7]

- **円環の 1/3 法則 [V3]**: 重み場つき円環 (24 点) の H1 主 bar が death/周長 =
  0.3367 (測地円の理論値 1/3) — persistence の**定量**アンカー (穴の個数ではなく
  birth/death を採点)。
- **穴スケールの寿命分離 [V4]**: 大小 2 穴 (16:8) が persistence 5.0 / 2.0 (比 2.50)
  の 2 bar に分離 — **v29.6 既知限界 (clique 順位 filtration では不滅バー) の解消**。
- **genus-2 [V5]**: 2 つの T² (5×5) の接着 (42 頂点, χ = −2): 構成 β = (1,4,1)・
  状態から支持 欠0余0 → **β₁ = 4 + 閉曲面 — 高 genus の初同定**。
- **敵対対照 [V6]**: narrow neck (K4 対 + 橋) は H1 捏造なし (persistence 0.000)・
  近接同サイズ 2 穴は 2 bar が同寿命で残る (合体しない)。
- **ノイズ安定性 [V7]**: bottleneck(D, D′) ≤ sup|Δd| — **persistence 安定性定理を
  σ = 2%/5% で機械照合** (0.0095 ≤ 0.0277 / 0.0496 ≤ 0.0589)。

## 5. 器械訂正 (gap 抽出器の最終凍結)

本版の設計走行で、v31.3 で導入したスケールガード付き gap 則の 2 つの故障モードを
発見・根治した (v313–v316 の 4 バイナリに統一適用・全て再走):

1. **旧規則 (v31.3)**: 窓・尾部を跨ぐ段差を評価せず break → 一様重み系 (16-cell 等)
   で唯一の本命段差を見逃し全辺を落とす。
2. **中間修正**: 跨ぎ段差を本命にすると、多段階系で物理段差を尾部跨ぎが上書き。
3. **最終規則 (凍結)**: 窓内 (両端 ≥ max·10⁻³) の最大対数段差が**有意 (≥ ln 3)** なら
   そこで切る — 有意段差がなければ窓内は単一クラスタ = 全て辺 (窓境界で切る)。

再走の結果: v313 (11 PASS)・v314 (9 PASS) は裁定不変。**v31.5 [N5] の GS V=4 (CDW) は
「支持生存」→「支持破れ (全対 — スケール分離消失)」に更新** — 暫定規則は非有意段差
(対蹠/bond 比 0.66) で偶然 ring に切れていた。当初の物理予想が最終器械の下で回復
(uft-v31.5.md 監査注記・claims QRN-BRIDGE-016 更新)。

もう 1 件の器械訂正: **測定 lane の dt をスペクトル半径でスケール** (dt_eff =
dt_base/‖h‖₁) — 1D 調整の固定 dt は次数 14 の T³ 骨格で高階微分誤差が O(1) になる
(1D 調整値の暗黙拡張は本期の禁止事項そのもの — 適応則を器械契約に昇格)。
