**Version**: v29.5 (第三十期, PROMPT/11 第三課題「一意性より先に非一意性を探索する」)
**Date**: 2026-07-30
**Sim**: `sim/src/bin/v295_collision_atlas.rs` → `results/v295_collision_atlas.txt`
(9 検査 PASS) / `results/v295_collision_atlas.json`
**位置づけ**: 状態だけから幾何を一意に決める普遍写像 ρ ↦ g は存在しない (同一の
積状態は任意の非同型グラフに置ける)。成立し得るのは「状態族 + 局所代数 +
応答チャネル → 幾何の**同値類**」という仮定つき写像である。本版はその境界を
**小系の全数探索の証明書**として機械化した — 反例 2 件の発見を含む。

## 0. 方法 (探索領域と証明書構造)

- **領域**: n = 4..7 の連結グラフ同型類 **全数** (6/21/112/853 — 自前列挙
  [canonical form = 全置換 min] が OEIS A001349 と一致 [C0])。各グラフに
  H = −A (隣接ホッピング)・**半充填基底状態** (縮退 Fermi 境界は「シェル分数
  占有」規則 — 置換共変・決定的)。
- **チャネル**: 静的 B1-MI / B3-COV / B5-QFI (凍結 v29/v30 節の逐語コピー —
  atlas は凍結器械そのものを検査する)、動的 KIN (運動学 t\* 行列, ε = 1e-3,
  dt = 0.05)。
- **識別余裕 (identifiability margin)**: 全非同型対の
  min_π ‖X∘π − X′‖∞。**証明書構造**: 整列多重集合距離は任意の置換整列の下界
  ([C2] が標本 200 対 × 4 チャネルで機械検査) — 下界昇順に厳密評価し、下界 ≥
  現行最小に達した時点で停止 = margin の厳密性が全対について保証される。

## 2. 発見 1 [C7a] — 静的核の厳密衝突対 (最小反例, n = 6)

**mask 692 = P6 (パス, 5 辺) と mask 693 (単環, 6 辺)**: 非同型 (次数列も辺数も
異なる)・**cospectral ですらない** (スペクトル ±{1.80, 1.25, 0.45} vs
±{2.25, 0.80, 0.55}) のに、**B1/B3/B5 の全静的核が FP ゼロ (≤ 1.9e-14) で
置換一致**する。

- **機構**: 両者は二部・ゼロモードなしで、半充填基底状態の相関行列は
  C = (1 − sign(A))/2。**静的核 (基底状態の任意の関数) は sign(A) までしか
  見えない** — この対は sign(A) が置換同値 (スペクトルは sign に入らないため
  不一致でよい)。
- **動的チャネルが分離する**: KIN 距離 = **0.50** (t\* は A 自身のダイナミクスを
  見る)。→ PROMPT/11 が予想した定理の形「静的単一状態だけでは不可能だが、
  応答チャネルを加えると同定可能」の**最小機械実例**。
- 同値類の言明: 静的読み出しに対する非自明な同値類
  [g]\_~ = {sign(A) が置換同値なグラフ} が実在し、その最小代表対が (P6, 693)。

## 3. 発見 2 [C7b] — Petersen 誤認 (縮退 + fallback の捏造)

非多様体裁定表 [C6b]: star S7 / K7 / K3,3 / Q3 / prism は誤認なし (幾何なし
または部分構造)。**Petersen (3 正則・頂点推移) だけが「10 ノードの完全 1D
path」と誤認**された。

- **機構 (機械同定)**: 頂点推移性で全 15 辺のカーネルが厳密縮退
  (拡がり 3.8e-16) → 添字順 tie-break で mutual top-2 が断片化 (被覆 < 90%)
  → v30 の Occam 直行路は幾何を返さず、**v29 橋つき fallback が非辺
  (距離 2 対, 核比 1/49) を継いで path を捏造** (選択辺に非辺が混入している
  ことが fallback 発火の機械的証拠)。
- **設計入力 (v29.6 へ)**: 縮退カーネル (対称グラフ) では fallback の前に
  縮退検査で「裁定保留」を返すべき。**凍結 v30 は変更しない** — HOLD-5 の
  裁定は縮退のない不均一系で、この故障モードの射程外 (資格条件の隣接 100%
  検査が真値照合で誤認を落とすため holdout の結論は影響を受けない)。

## 4. no-go 側の機械化

- **[C4] 無情報状態**: C = I/2 では全カーネル < W_FLOOR → readout は幾何なしを
  返す (幾何を捏造しない)。「状態族の仮定が identifiability の前提」の機械化。
- **[C5] factorization は選べない**: C12 均一リング基底状態を 5 通りに群化 —
  隣接対・オフセット対・三つ組 (局所粗視化) は**整合する円環**、反対点対
  (antipodal quotient) は**別の自己整合幾何 (C6)**、ランダム対は円環なし。
  readout は与えられた factorization を幾何化するだけで、factorization 自体を
  選定できない — FactorizationBridge の空隙 (v29.2 の二層分離) の機械記録。
- **[C6a] 静的位相の偽陰性**: C16 + 弦 (0–8, 強度 g) は **g = 0.05..1.0 の全域で
  静的 top-2 がクリーン円環と誤読** (弦は常に第 3 位で top-2 から漏れる) — 一方
  **動的 t\* は全域で短絡を即検出** (r = t\*(0→8)/t\*(0→4) = 0.125 ≪ 2)。
  静的位相資格だけでは隠れた弱結合を排除できない — 応答チャネルの必要性の実例。

## 5. 裁定の要約 (identifiability/no-go 境界)

> **成立**: n ≤ 7 連結グラフ族・半充填自由フェルミオン・与えられた因子分解の
> 下で、静的核 + 動的チャネルの併用は全数識別 (margin > 0 の証明書つき —
> 静的衝突対 (P6, 693) は KIN が 0.5 で分離)。
> **不成立 (no-go)**: (i) 静的単独 — sign(A) 同値類 (最小 n=6)。(ii) 動的 KIN
> 単独 — 閾値量子化の大量衝突。(iii) 無情報状態 — 幾何なし。(iv) factorization
> の選定 — readout の射程外。(v) 静的位相資格 — 弱い弦の偽陰性 (全 g)。
> (vi) 縮退カーネル — fallback が幾何を捏造し得る (Petersen)。

「反例が見つからなかった」ではなく、**探索領域 (992 グラフ全数)・margin・
衝突クラス・機構**を証明書として出した — PROMPT/11 第三課題の要求どおり。

  非辺混入から **fallback 経路の捏造**と機械同定して訂正 (印字された機構は

- 弦の掃引は「窓」を仮定していたが実態は「全域」— 静的 top-2 の弦見落としは
  g = 1.0 (等強度!) でも起きる。1D 臨界相関の距離減衰が結合強度より支配的。
